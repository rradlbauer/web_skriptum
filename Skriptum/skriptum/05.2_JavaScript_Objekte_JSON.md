# 05.2 JavaScript – Objekte & JSON

JavaScript-**Objekte** sind Sammlungen von Schlüssel-Wert-Paaren. Zusammen mit **JSON** sind sie die Grundlage für den Datenaustausch zwischen Client und Server (z. B. mit einer Spring-Boot-REST-API).

## Objekte

Ein Objekt wird mit geschweiften Klammern `{}` angelegt:

```js
const patient = {
    id: 1,
    name: "Anna Maier",
    age: 42,
    diagnosis: "Grippe"
};
```

Zugriff auf Werte:

```js
console.log(patient.name);       // Anna Maier   (Punkt-Notation)
console.log(patient["name"]);    // Anna Maier   (Klammer-Notation)
```

Werte ändern und hinzufügen:

```js
patient.age = 43;
patient.room = 102;      // neues Attribut
console.log(patient.room);   // 102
```

### Verschachtelte Objekte

Objekte können Objekte enthalten:

```js
const doctor = {
    firstName: "Julia",
    lastName: "Berg",
    address: {
        street: "Klinikgasse 1",
        city: "Wien"
    }
};

console.log(doctor.address.city);   // Wien
```

## Arrays von Objekten

Der häufigste Fall in der Webentwicklung: mehrere Datensätze als Array von Objekten.

```js
const patients = [
    { id: 1, name: "Anna Maier", diagnosis: "Grippe" },
    { id: 2, name: "Bernd Huber", diagnosis: "Migräne" },
    { id: 3, name: "Eva Wagner", diagnosis: "Diabetes" }
];

for (let p of patients) {
    console.log(`Patient ${p.name} hat ${p.diagnosis}`);
}
```

Dieses Format entspricht genau dem, was eine REST-API liefert (Kapitel 07.4 und 09.0).

## JSON

**JSON (JavaScript Object Notation)** ist ein **Textformat** zum Austausch von Daten. Es sieht wie JavaScript-Objekte aus, ist aber nur **reiner Text** – es kann gespeichert, übertragen und von jedem System gelesen werden.

JSON-Beispiel:

```json
{
  "id": 1,
  "name": "Anna Maier",
  "age": 42,
  "diagnosis": "Grippe"
}
```

Regeln von JSON:
- Attribute (Keys) stehen **immer in doppelten Anführungszeichen** `"`
- Werte: Strings in Anführungszeichen, Zahlen, `true`/`false`, `null`, Arrays `[]`, Objekte `{}`
- Keine Funktionen, keine Kommentare

## Umwandeln: Objekt ↔ JSON

| Methode | Richtung | Wirkung |
|---------|----------|---------|
| `JSON.stringify(obj)` | Objekt → JSON-Text | konvertiert ein Objekt/Array in einen JSON-String |
| `JSON.parse(jsonText)` | JSON-Text → Objekt | konvertiert einen JSON-String in ein Objekt |

```js
const patient = { id: 1, name: "Anna Maier", age: 42 };

const jsonText = JSON.stringify(patient);
console.log(jsonText);
// {"id":1,"name":"Anna Maier","age":42}

const parsed = JSON.parse(jsonText);
console.log(parsed.name);   // Anna Maier
```

### Beispiel mit einem Array

```js
const patients = [
    { id: 1, name: "Anna Maier" },
    { id: 2, name: "Bernd Huber" }
];

const json = JSON.stringify(patients);
console.log(json);
// [{"id":1,"name":"Anna Maier"},{"id":2,"name":"Bernd Huber"}]

const back = JSON.parse(json);
console.log(back[1].name);   // Bernd Huber
```

Dieses Umwandeln ist die Basis für:
- das **Speichern** von Formulardaten in Web Storage (Kapitel 07.3)
- das **Übertragen** von Daten an die REST-API und zurück (Kapitel 07.4)
