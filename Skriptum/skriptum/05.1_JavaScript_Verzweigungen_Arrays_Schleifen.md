# 05.1 JavaScript – Verzweigungen, Arrays & Schleifen

Dieses Kapitel behandelt die Kontrollstrukturen, die du aus Java und Python kennst, in JavaScript: **Verzweigungen**, **Arrays** und **Schleifen**.

## Verzweigungen (if / else if / else)

```js
let temperature = 38.5;

if (temperature >= 38) {
    console.log("Fieber");
} else if (temperature >= 37) {
    console.log("Leicht erhöhte Temperatur");
} else {
    console.log("Keine erhöhte Temperatur");
}
```

### switch

```js
let bloodType = "A";

switch (bloodType) {
    case "A":
        console.log("Blutgruppe A");
        break;
    case "B":
        console.log("Blutgruppe B");
        break;
    default:
        console.log("Unbekannt");
}
```

Falls du Java kennst: `break` verhindert, dass die folgenden `case`-Blöcke ebenfalls ausgeführt werden.

## Arrays

Ein **Array** ist eine geordnete Liste von Werten.

```js
const patients = ["Anna Maier", "Bernd Huber", "Eva Wagner"];
console.log(patients[0]);   // "Anna Maier"
console.log(patients.length); // 3
```

### Wichtige Array-Methoden

| Methode | Wirkung |
|---------|---------|
| `push(wert)` | Wert am Ende hinzufügen |
| `pop()` | letztes Element entfernen |
| `shift()` | erstes Element entfernen |
| `indexOf(wert)` | Index eines Elements suchen |
| `includes(wert)` | prüfen, ob Wert enthalten ist |
| `join(" ")` | Elemente zu String verbinden |

```js
patients.push("Karl Gruber");
patients.pop();
console.log(patients.join(", "));
```

### Hinweis auf andere nützliche Methoden

Mit `map`, `filter` und `reduce` kannst du Arrays deklarativ bearbeiten – ähnlich der Streaming-API aus dem Java-Skriptum:

```js
const names = patients.map(p => p.toUpperCase());
const longNames = patients.filter(p => p.length > 10);
```

Die Schreibweise `p => ...` ist ein **Arrow Function** (Pfeilfunktion), das Lambda-Pendant aus JavaScript.

## Schleifen (for, for...of, while)

### Klassische for-Schleife

```js
for (let i = 0; i < 5; i++) {
    console.log(`Patient ${i}`);
}
```

### for...of über ein Array

```js
for (let patient of patients) {
    console.log(patient);
}
```

### while-Schleife

```js
let retries = 0;
while (retries < 3) {
    console.log(`Versuch ${retries + 1}`);
    retries++;
}
```

## Beispiel: Triage

```js
function triage(heartRate) {
    let category;
    if (heartRate < 60) {
        category = "langsam";
    } else if (heartRate <= 100) {
        category = "normal";
    } else {
        category = "schnell";
    }
    return category;
}

const rates = [55, 72, 110];
for (let rate of rates) {
    console.log(`Herzfrequenz ${rate}: ${triage(rate)}`);
}
```

## Zusammenfassung

### Wichtige Begriffe
- `if`, `else if`, `else`, `switch`
- Arrays: `push`, `pop`, `length`, `forEach`
- Schleifen: `for`, `for...of`, `while`
- Arrow Functions `=>`

### Das sollst du können
- Entscheidungen mit `if`/`switch` programmieren
- Arrays anlegen, lesen und verändern
- Mit `for` und `for...of` über Arrays iterieren
