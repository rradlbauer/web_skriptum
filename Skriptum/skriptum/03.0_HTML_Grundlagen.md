# 03.0 HTML – Grundlagen

**HTML (HyperText Markup Language)** ist die **Auszeichnungssprache** (Markup-Sprache), mit der die **Struktur** und der **Inhalt** einer Webseite beschrieben werden. HTML ist keine Programmiersprache – es beschreibt, *was* auf der Seite steht, nicht, wie es *funktioniert* oder *gestaltet* ist (Letzteres übernimmt CSS, siehe Kapitel 04).

## Der Aufbau einer HTML-Seite

Eine minimale HTML-Seite sieht so aus:

```html
<!DOCTYPE html>
<html lang="de">
<head>
    <meta charset="UTF-8">
    <title>Patientenverwaltung</title>
</head>
<body>
    <h1>Willkommen in der Patientenverwaltung</h1>
    <p>Hier werden Patientendaten verwaltet.</p>
</body>
</html>
```

| Baustein | Bedeutung |
|----------|-----------|
| `<!DOCTYPE html>` | Kennzeichnet das Dokument als HTML5 |
| `<html>` | Wurzel-Element der Seite |
| `<head>` | Metadaten, die nicht direkt angezeigt werden (Titel, Codierung, ...) |
| `<meta charset="UTF-8">` | Zeichencodierung (wichtig für Umlaute wie ä, ö, ü) |
| `<title>` | Titel, der im Browser-Tab erscheint |
| `<body>` | Sichtbarer Inhalt der Seite |

## Elemente, Tags und Attribute

### Elemente

Ein **Element** besteht aus einem **Start-Tag**, dem **Inhalt** und einem **End-Tag**:

```html
<p>Hallo Patient</p>
```

- `<p>` ist der Start-Tag
- `Hallo Patient` ist der Inhalt
- `</p>` ist der End-Tag

Einige Elemente haben keinen Inhalt (leere Elemente), z. B. `<br>` (Zeilenumbruch) oder `<img>` (Bild).

### Attribute

**Attribute** geben einem Element zusätzliche Informationen. Sie stehen im Start-Tag:

```html
<a href="https://example.org">Link zur Arztpraxis</a>
<img src="foto.jpg" alt="Portrait des Patienten">
<input type="text" id="name">
```

- `href` beim `<a>`-Element: das Ziel des Links
- `src` und `alt` beim `<img>`-Element: Quelle und Alternativtext des Bildes
- `type` und `id` beim `<input>`-Element: Art und Kennzeichnung des Eingabefelds

## Wichtige Elemente im Überblick

| Element | Bedeutung |
|---------|-----------|
| `<h1>` ... `<h6>` | Überschriften (1 = größte) |
| `<p>` | Absatz (paragraph) |
| `<a>` | Link |
| `<img>` | Bild |
| `<ul>`, `<ol>`, `<li>` | Listen (unsorted/ordered) |
| `<table>`, `<tr>`, `<td>`, `<th>` | Tabellen |
| `<form>`, `<input>`, `<button>`, `<select>` | Formulare |
| `<div>`, `<span>` | Container zum Gruppieren |
| `<header>`, `<nav>`, `<main>`, `<footer>` | Struktur-/Semantik-Elemente |

## Zeilenumbruch und Leerzeichen

Mehrere Leerzeichen und Zeilenumbrüche im HTML-Quelltext werden vom Browser zu **einem** Leerzeichen zusammengefasst. Für erzwungene Umbrüche nutzt du `<br>`:

```html
<p>Zeile 1<br>Zeile 2</p>
```

## Kommentare

HTML-Kommentare werden nicht angezeigt:

```html
<!-- Das ist ein Kommentar -->
```

## Zusammenfassung

### Wichtige Begriffe
- HTML, Element, Start-Tag, End-Tag, Inhalt
- Attribut (`href`, `src`, `alt`, `id`, `type`)
- `<html>`, `<head>`, `<body>`, `<meta>`, `<title>`
- Überschriften, Absätze, Links, Bilder

### Das sollst du können
- Eine einfache HTML-Seite von Grund auf schreiben
- Elemente in Tag, Inhalt und Attribut zerlegen
- Wichtige HTML-Elemente benennen und einsetzen
