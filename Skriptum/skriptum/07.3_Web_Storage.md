# 07.3 TypeScript – Web Storage (sessionStorage / localStorage)

Der **Web Storage** des Browsers erlaubt es, Daten im Browser zu speichern. Das ist nützlich, um z. B. Formulardaten zu erhalten, wenn die Seite neu geladen wird – ganz ohne Server. In TypeScript kommt dabei der spannende Punkt hinzu: `JSON.parse` liefert `any`, deshalb **typisierst** du das Ergebnis.

## Die beiden Storage-Bereiche

| | `sessionStorage` | `localStorage` |
|---|---|---|
| Lebensdauer | bis der Tab geschlossen wird | bleibt dauerhaft erhalten |
| Gültigkeit | pro Browser-Tab | pro Domain (Herkunft) |
| typischer Einsatz | Formulardaten während der Sitzung | Einstellungen, dauerhafte Daten |

Beide funktionieren gleich: Daten werden als **Schlüssel-Wert-Paare** gespeichert – und zwar **immer als Text (Strings)**.

## Grundoperationen

| Methode | Wirkung |
|---------|---------|
| `localStorage.setItem(key, value)` | Wert speichern |
| `localStorage.getItem(key)` | Wert lesen (oder `null`) |
| `localStorage.removeItem(key)` | einen Eintrag löschen |
| `localStorage.clear()` | alles löschen |

Für `sessionStorage` gelten dieselben Methoden.

```ts
localStorage.setItem("name", "Anna Maier");
const storedName: string | null = localStorage.getItem("name");
console.log(storedName);   // Anna Maier
```

## Objekte speichern: JSON ist der Schlüssel

Web Storage speichert **nur Text**. Zum Speichern verwendest du `JSON.stringify` – zum Lesen `JSON.parse` und **typisierst das Ergebnis** mit einem Interface:

```ts
interface Patient {
    name: string;
    age: number;
    diagnosis: string;
}

const patient: Patient = {
    name: "Anna Maier",
    age: 42,
    diagnosis: "Grippe"
};

// Speichern
localStorage.setItem("patient", JSON.stringify(patient));

// Wiederherstellen – JSON.parse liefert any, wir typisieren mit as Patient
const stored = localStorage.getItem("patient");
if (stored !== null) {
    const restoredPatient = JSON.parse(stored) as Patient;
    console.log(restoredPatient.name);   // Anna Maier
}
```

> **TypeScript-Besonderheit:** `JSON.parse` gibt `any` zurück. Mit `as Patient` sagst du dem Compiler, welche Struktur erwartet wird. Eine Laufzeit-Prüfung kann zusätzlich sicherstellen, dass die Daten wirklich zum Interface passen.

## Formulardaten speichern und wiederherstellen

Häufigster Anwendungsfall: Der Benutzer gibt ein Formular aus, lädt die Seite neu und die Daten sollen **wiederhergestellt** werden.

### Speichern beim Absenden/Eingabe

```ts
interface PatientFormData {
    name: string;
    age: number;
    ward: string;
}

const form = document.getElementById("patientForm") as HTMLFormElement;

form.addEventListener("submit", (event: Event) => {
    event.preventDefault();

    const patient: PatientFormData = {
        name: (document.getElementById("name") as HTMLInputElement).value,
        age: Number((document.getElementById("age") as HTMLInputElement).value),
        ward: (document.getElementById("ward") as HTMLSelectElement).value
    };

    localStorage.setItem("currentPatient", JSON.stringify(patient));
});
```

### Wiederherstellen beim Laden der Seite

```ts
function restorePatientForm(): void {
    const stored = localStorage.getItem("currentPatient");
    if (stored === null) {
        return;   // nichts gespeichert
    }

    const patient = JSON.parse(stored) as PatientFormData;

    (document.getElementById("name") as HTMLInputElement).value = patient.name;
    (document.getElementById("age") as HTMLInputElement).value = String(patient.age);
    (document.getElementById("ward") as HTMLSelectElement).value = patient.ward;
}

restorePatientForm();
```

Die Funktion wird direkt nach dem Laden der Seite aufgerufen (das TypeScript wird zu einem `<script>` compiliert, das am Ende des `<body>` steht).

## Beispiel: Session-Storage für Zwischenzustände

```ts
interface Draft {
    name: string;
    notes: string;
}

function autoSave(): void {
    const draft: Draft = {
        name: (document.getElementById("name") as HTMLInputElement).value,
        notes: (document.getElementById("notes") as HTMLTextAreaElement).value
    };
    sessionStorage.setItem("draft", JSON.stringify(draft));
}

// optional: Rückgabetyp Prüf-Funktion, die sicher typisiert
function getDraft(): Draft | null {
    const stored = sessionStorage.getItem("draft");
    if (stored === null) {
        return null;
    }
    return JSON.parse(stored) as Draft;
}
```

> **Hinweis:** Web Storage ist **kein** Ersatz für eine echte Datenbank – die Daten liegen nur im Browser eines einzelnen Benutzers und können dort gelesen werden. Medizinische Daten gehören in eine sichere Server-Datenbank; Web Storage eignet sich für Zwischenstände und kleine Einstellungen.

## Zusammenfassung

### Wichtige Begriffe
- `sessionStorage`, `localStorage`
- `setItem`, `getItem`, `removeItem`, `clear`
- `JSON.stringify` / `JSON.parse`, Typ-Assertion `as Patient`
- `string | null` als Rückgabetyp von `getItem`

### Das sollst du können
- Werte in localStorage/sessionStorage schreiben und lesen
- Objekte/Arrays mit JSON speichern und **typisiert** wiederherstellen
- Formulardaten speichern und beim Laden wiederherstellen
