# 04.2 CSS – Flexbox, Grid & Media Queries

In diesem Kapitel lernst du die beiden wichtigsten **Layout-Systeme** von CSS – **Flexbox** und **Grid** – sowie **Media Queries** für das responsive Design.

## Flexbox

**Flexbox** (`display: flex`) richtet Elemente in einer **Zeile oder Spalte** aus. Sie ist ideal, um Elemente horizontal oder vertikal zu zentrieren und zu verteilen.

### Grundaufbau

```css
.container {
    display: flex;
}
```

Die Kind-Elemente liegen dann automatisch **nebeneinander**.

### Wichtige Flexbox-Eigenschaften

| Eigenschaft | Bedeutung |
|-------------|-----------|
| `flex-direction` | `row` (Standard, nebeneinander) oder `column` (untereinander) |
| `justify-content` | Ausrichtung auf der Hauptachse (z. B. `center`, `space-between`) |
| `align-items` | Ausrichtung auf der Querachse (z. B. `center`) |
| `gap` | Abstand zwischen den Elementen |

```css
.navigation {
    display: flex;
    justify-content: space-between;
    align-items: center;
}
```

### Flex und Verteilung

Mit `justify-content` verteilst du Elemente:

- `flex-start` – am Anfang
- `flex-end` – am Ende
- `center` – zentriert
- `space-between` – gleicher Abstand zwischen den Elementen
- `space-around` – gleicher Abstand rundherum

## Grid

**Grid** (`display: grid`) teilt den verfügbaren Platz in ein **Raster** aus Zeilen und Spalten ein. Es eignet sich für komplexere Layouts.

### Grundaufbau

```css
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
}
```

- `grid-template-columns`: Definition der Spalten (hier: drei gleich breite Spalten)
- `gap`: Abstand zwischen den Zellen
- `1fr` = 1 Bruchteil (fraction) der verfügbaren Breite

```css
.dashboard {
    display: grid;
    grid-template-columns: 2fr 1fr;
    gap: 16px;
}
```

Zwei Spalten, wobei die linke **doppelt so breit** ist wie die rechte.

## Media Queries

**Media Queries** erlauben es, CSS-Regeln **nur unter bestimmten Bedingungen** anzuwenden – meist abhängig von der Bildschirmbreite. Damit setzt du responsives Design um.

### Grundaufbau

```css
@media (max-width: 600px) {
    .grid-container {
        grid-template-columns: 1fr;
    }
}
```

Bedeutung: unterhalb von **600 px** Breite wird das Grid auf **eine Spalte** reduziert.

### Häufige Breakpoints

| Bedingung | Gerät |
|-----------|-------|
| `max-width: 480px` | kleine Smartphones |
| `max-width: 768px` | Tablets / hochkant |
| `max-width: 992px` | kleinere Laptops |
| größer | Desktop |

### Beispiel: Verlauf

```css
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
}

@media (max-width: 768px) {
    .grid-container {
        grid-template-columns: 1fr;
    }
}
```

Auf großen Bildschirmen: drei Spalten. Auf Tablets/Handys: eine Spalte – ein typisches responsives Verhalten.

## Flexbox vs. Grid – wann was?

| | Flexbox | Grid |
|---|---------|------|
| Achsen | ausgerichtet auf einer Achse | zweidimensional (Zeilen + Spalten) |
| Einsatz | Zeilen/Listen, kleine Gruppen, Zentrieren | gesamte Seiten-Layouts, Raster |
| Merksatz | legt Elemente in einer Linie | legt Elemente in ein Raster |

### Wichtige Begriffe
- Flexbox: `display: flex`, `justify-content`, `align-items`, `flex-direction`, `gap`
- Grid: `display: grid`, `grid-template-columns`, `1fr`
- Media Queries: `@media (max-width: ...)`, Breakpoints

### Das sollst du können
- Ein einfaches Layout mit Flexbox umsetzen
- Ein Layout mit Grid in Spalten aufteilen
- Mit Media Queries das Layout auf kleine Geräte umschalten
