# 04.1 CSS – Klassen, Pseudo-Klassen & Responsives Design

Dieses Kapitel vertieft die Arbeit mit **Klassen** in CSS, behandelt **Pseudo-Klassen** und führt in das **responsive Design** ein.

## Klassen in CSS

Klassen sind das wichtigste Werkzeug, um Elemente gezielt zu gestalten und Wiederholungen zu vermeiden. Mehrere Klassen können kombiniert werden:

```html
<div class="karte gross">...</div>
<div class="karte klein">...</div>
```

```css
.karte {
    border: 1px solid #ccc;
    padding: 16px;
}
.gross {
    width: 400px;
}
.klein {
    width: 200px;
}
```

Eine Klasse kann auf **beliebig viele** Elemente angewendet werden – das ist der Unterschied zur eindeutigen `id`.

## Pseudo-Klassen

Eine **Pseudo-Klasse** beschreibt einen **bestimmten Zustand** eines Elements. Sie wird mit `:` an den Selektor angehängt.

### Zustands-Pseudo-Klassen

| Pseudo-Klasse | Bedeutung |
|---------------|-----------|
| `:hover` | Maus über dem Element |
| `:focus` | Element hat den Fokus (z. B. Eingabefeld) |
| `:active` | Element wird gerade aktiviert (geklickt) |
| `:visited` | Link wurde bereits besucht |

```css
a:hover {
    color: #c0392b;
}
input:focus {
    border-color: #2980b9;
}
```

### Struktur-Pseudo-Klassen

| Pseudo-Klasse | Bedeutung |
|---------------|-----------|
| `:first-child` | erstes Kind-Element |
| `:last-child` | letztes Kind-Element |
| `:nth-child(n)` | n-tes Kind-Element |

```css
tr:nth-child(even) {
    background-color: #f2f2f2;
}
```

Mit `:nth-child(even)` kannst du z. B. Tabellen **zeilenweise abwechselnd** färben (zebragestreift).

## Responsives Design

**Responsives Design** bedeutet: Die Seite passt sich **automatisch** an die Bildschirmgröße des Geräts an (Handy, Tablet, Desktop).

Grundprinzipien:

- Flexible Größen anstelle fester Breiten verwenden (z. B. `max-width`, `%`, `rem` statt `px`)
- **Media Queries** (Kapitel 04.2) zum Anpassen unterhalb bestimmter Breiten
- Flexible Layouts mit **Flexbox** (Kapitel 04.2) und **Grid** (Kapitel 04.2)
- Das **Viewport-Meta-Tag**, damit mobile Browser korrekt skalieren:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

### Beispiel für flexible Breite

```css
main {
    max-width: 960px;
    margin: 0 auto;   /* horizontal zentrieren */
}
```

Die Seite ist damit auf großen Monitoren maximal 960 px breit (zentriert) und auf kleineren Geräten schmaler, ohne horizontales Scrollen.

## Mobile-First

Beim **Mobile-First**-Ansatz gestaltest du zuerst die schmale (mobile) Ansicht und ergänzt dann per Media Queries die breitere Ansicht. Das ist heute der übliche Ansatz.

## Zusammenfassung

### Wichtige Begriffe
- Klassen (`class`), kombinierte Klassen
- Pseudo-Klassen: `:hover`, `:focus`, `:active`, `:visited`, `:nth-child`
- Responsives Design, Viewport-Tag

### Das sollst du können
- Klassen gezielt kombinieren und einsetzen
- Häufige Pseudo-Klassen anwenden (z. B. `:hover`, `:nth-child`)
- Die Grundidee des responsiven Designs erklären
