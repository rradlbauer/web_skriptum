# 04.0 CSS – Selektoren & Styling

**CSS (Cascading Style Sheets)** ist die Sprache, mit der du das **Aussehen** einer HTML-Seite festlegst: Farben, Schriftarten, Abstände, Rahmen, Layout usw. HTML beschreibt den **Inhalt** und die **Struktur**, CSS das **Design**.

## CSS einbinden

Es gibt drei Möglichkeiten, CSS in eine Seite einzubinden:

### 1. Externe Datei (empfohlen)

```html
<head>
    <link rel="stylesheet" href="styles.css">
</head>
```

### 2. Im `<style>`-Element

```html
<head>
    <style>
        p { color: blue; }
    </style>
</head>
```

### 3. Inline-Attribut `style`

```html
<p style="color: blue;">Dieser Absatz ist blau</p>
```

Die **externe Datei** ist am saubersten: Trennung von Inhalt und Gestaltung.

## Grundsatz von CSS

Eine CSS-Regel besteht aus einem **Selektor** und einem **Deklarationsblock** mit **Deklarationen** (Eigenschaft: Wert):

```css
p {
    color: blue;
    font-size: 16px;
}
```

- `p` ist der Selektor (welches Element)
- `color`, `font-size` sind Eigenschaften
- `blue`, `16px` sind Werte
- Jede Deklaration endet mit `;`

## Selektoren

Ein **Selektor** bestimmt, welche Elemente gestylt werden.

### Element-Selektor

Wählt alle Elemente eines Typs:

```css
h1 {
    color: #2c3e50;
}
```

### Klassen-Selektor (`.`)

Wählt alle Elemente mit einer bestimmten `class`:

```css
.karte {
    border: 1px solid #ccc;
}
```

### ID-Selektor (`#`)

Wählt das Element mit einer bestimmten `id` (eindeutig):

```css
#navi {
    background-color: #34495e;
}
```

### Kombinierte Selektoren

```css
div.karte { ... }        /* div mit class=“karte” */
main p { ... }           /* p innerhalb von main (Nachfahre) */
ul > li { ... }          /* direkte li-Kinder von ul */
```

## Wichtige Styling-Eigenschaften

| Eigenschaft | Bedeutung |
|-------------|-----------|
| `color` | Textfarbe |
| `background-color` | Hintergrundfarbe |
| `font-size` | Schriftgröße |
| `font-family` | Schriftart |
| `font-weight` | Fett (z. B. `bold`) |
| `border` | Rahmen |
| `padding` | Innenabstand |
| `margin` | Außenabstand |
| `border-radius` | abgerundete Ecken |
| `width`, `height` | Breite, Höhe |

```css
.karte {
    background-color: #f9f9f9;
    border: 1px solid #ddd;
    border-radius: 8px;
    padding: 16px;
    margin: 12px;
}
```

## Kaskade und Spezifität

"**Cascading**" bedeutet, dass mehrere Regeln aufeinander wirken können. Bei Konflikten entscheidet die **Spezifität**:

`Inline-style` > `#id` > `.class` > `Element`

Gleiche Spezifität: Die **zuletzt** definierte Regel gewinnt.
