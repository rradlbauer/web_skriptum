# 03.2 HTML – div, span & weitere wichtige Elemente

Neben Tabellen, Listen und Formularen gibt es weitere wichtige HTML-Elemente. Besonders wichtig zum **Strukturieren** und **Gestalten** sind `div` und `span`.

## `<div>` – der Block-Container

Ein `<div>` (division) ist ein **Block-Element**, das dazu dient, mehrere Elemente zu **Gruppen** zusammenzufassen. Es besitzt selbst keine besondere Darstellung, ist aber der wichtigste "Baukasten" für das Layout – vor allem in Kombination mit CSS.

```html
<div class="karte">
    <h2>Anna Maier</h2>
    <p>Diagnose: Grippe</p>
    <p>Zimmer: 102</p>
</div>
```

Ein `div` beginnt auf einer **neuen Zeile** und nimmt die volle verfügbare Breite ein (Block-Element).

## `<span>` – der Inline-Container

Ein `<span>` ist ein **Inline-Element**. Es gruppiert einen Teil innerhalb einer Textzeile, ohne die Zeile umzubrechen. Es wird häufig verwendet, um einen Ausschnitt **einzufärben** oder **hervorzuheben**.

```html
<p>Der Patient hat <span class="wichtig">Fieber</span> und Husten.</p>
```

Ein `span` bleibt **innerhalb** der Zeile (inline) und nimmt nur die Breite seines Inhalts ein.

## Block- vs. Inline-Elemente

| Eigenschaft | Block-Element | Inline-Element |
|-------------|---------------|----------------|
| beginnt auf neuer Zeile | ja | nein |
| benötigt eigene Zeile | ja | bleibt in der Zeile |
| Beispiele | `<div>`, `<p>`, `<h1>`, `<ul>` | `<span>`, `<a>`, `<strong>`, `<em>` |

## Klassen und IDs zur Auswahl

Mit den Attributen `class` und `id` bereitest du Elemente für **CSS** (Styling) und **JavaScript** (Zugriff) vor:

- **`class`** – kann bei mehreren Elementen vorkommen (Gruppe)
- **`id`** – darf pro Seite nur **einmal** vorkommen (eindeutig)

```html
<div class="karte" id="karte-anna">
    <h2>Anna Maier</h2>
</div>
```

## Semantische Struktur-Elemente

Anstatt überall `div` zu verwenden, gibt es **semantische Elemente**, die die Bedeutung eines Bereichs klarer machen (besser für Zugänglichkeit und Suchmaschinen):

| Element | Bedeutung |
|---------|-----------|
| `<header>` | Kopfbereich der Seite / eines Abschnitts |
| `<nav>` | Navigationsbereich |
| `<main>` | Hauptinhalt |
| `<section>` | inhaltlicher Abschnitt |
| `<article>` | eigenständiger Inhalt |
| `<aside>` | Randnotizen / Zusatzinformationen |
| `<footer>` | Fußbereich |

```html
<body>
    <header>
        <nav>... Navigation ...</nav>
    </header>
    <main>
        <section>... Patientendaten ...</section>
    </main>
    <footer>
        <p>© Klinik</p>
    </footer>
</body>
```

## Weitere wichtige Elemente

| Element | Bedeutung |
|---------|-----------|
| `<strong>` | wichtige / fette Hervorhebung |
| `<em>` | betonte / kursive Hervorhebung |
| `<br>` | Zeilenumbruch |
| `<hr>` | horizontaler Trennstrich |
| `<blockquote>` | Zitat |

## Zusammenfassung

### Wichtige Begriffe
- `<div>` (Block), `<span>` (Inline)
- Block-Element vs. Inline-Element
- `class`, `id`
- Semantische Elemente: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`

### Das sollst du können
- Den Unterschied zwischen Block- und Inline-Elementen erklären
- `div` und `span` sinnvoll einsetzen
- `class` und `id` korrekt verwenden
- Eine Seite mit semantischen Elementen strukturieren
