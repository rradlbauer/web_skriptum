# 07.0 Spring Boot – Grundlagen

**Spring Boot** kennst du bereits aus dem Java-Skriptum (Kapitel 13.x). In diesem Kapitel wiederholen wir die Grundlagen kurz und richten den Fokus auf das, was für **Web-Applikationen mit REST-API** wichtig ist: die Verbindung von Spring Boot mit einer Datenbank und die Auslieferung von Daten als JSON an JavaScript-Clients.

> Dieses Kapitel ist eine **Wiederholung und Vertiefung** von Kapitel 13.0 des Java-Skriptums.

## Was bietet Spring Boot?

- **Eingebauter Webserver** (Tomcat) – die Anwendung läuft direkt
- **Auto-Konfiguration** – Bausteine werden automatisch eingerichtet
- **Starter-Dependencies** – gepackte Bibliotheken über Maven
- Für uns zentral: die **REST-API**, über die der Browser (JavaScript) Daten abruft

## Die Hauptklasse

```java
package com.clinicaldiary;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class ClinicalDiaryApplication {
    public static void main(String[] args) {
        SpringApplication.run(ClinicalDiaryApplication.class, args);
    }
}
```

`@SpringBootApplication` kombiniert `@SpringBootConfiguration`, `@EnableAutoConfiguration` und `@ComponentScan`.

## Starters in der pom.xml

Für eine REST-API mit Datenbank brauchst du u. a.:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
```

| Starter | Wofür? |
|---------|--------|
| `spring-boot-starter-web` | Spring MVC, eingebauter Tomcat, REST-Endpoints |
| `spring-boot-starter-data-jpa` | JPA + Spring Data (Repositories) |
| `mysql-connector-j` | JDBC-Treiber für MySQL |

> **Merke:** Für eine reine REST-API mit JavaScript-Frontend brauchst du **kein Thymeleaf** – die Antworten sind JSON, keine HTML-Seiten.

## application.properties

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/clinical_diary
spring.datasource.username=root
spring.datasource.password=geheim

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
```

| Property | Bedeutung |
|----------|-----------|
| `spring.datasource.url` | JDBC-URL zur Datenbank |
| `spring.datasource.username` / `.password` | Zugangsdaten |
| `spring.jpa.hibernate.ddl-auto` | Schema-Verhalten (`update` erzeugt Tabellen automatisch) |
| `spring.jpa.show-sql` | generierte SQL-Ausdrücke anzeigen |

## Schichten-Architektur einer Spring-Boot-REST-Anwendung

```
HTTP (JSON)
   ↓
Controller   ← nimmt Anfragen entgegen, beantwortet sie
   ↓
Service      ← Geschäftslogik (optional, aber empfohlen)
   ↓
Repository   ← Datenbankzugriff (Spring Data JPA)
   ↓
MySQL
```

Diese Schichten lernst du in den Kapiteln 08.1 (Controller/Endpoints) und 08.2 (Entities/Repositories/Services) kennen.

## Starten und testen

```bash
mvn spring-boot:run
```

Die Anwendung läuft danach unter `http://localhost:8080/`. REST-Endpoints (z. B. `http://localhost:8080/api/patients`) kannst du direkt im Browser testen oder mit TypeScript (Kapitel 07.4) abrufen.
