# 05.0 JavaScript – Grundlagen

**JavaScript** ist die Programmiersprache des Browsers. Mit JavaScript werden Webseiten **interaktiv**: Inhalte werden verändert, Daten nachgeladen, Formulare geprüft – ganz ohne dass der Server eine neue Seite schickt.

JavaScript-Kenntnisse in Java/Python helfen dir: Variablen, Datentypen, Verzweigungen und Schleifen sind dir bereits vertraut. JavaScript ist allerdings **dynamisch typisiert** (wie Python) und verwendet andere Syntaxdetails.

## JavaScript einbinden

### Innerhalb des HTML-Dokuments

```html
<script>
    console.log("Hallo Patient");
</script>
```

### Externe JavaScript-Datei (empfohlen)

```html
<script src="script.js"></script>
```

> Empfehlung: Das `<script>`-Tag am Ende des `<body>` platzieren, damit das HTML zuerst geladen ist.

## Variablen

Variablen werden mit `let` (veränderbar) oder `const` (konstant) deklariert. `var` ist veraltet und sollte nicht mehr verwendet werden.

```js
let name = "Anna Maier";
const age = 42;
let isInsured = true;

name = "Anna M.";
```

- `const` – Wert darf später nicht neu zugewiesen werden
- `let` – Wert darf später geändert werden

## Datentypen

JavaScript kennt folgende Grund-Datentypen (dynamische Typisierung: der Typ wird aus dem Wert abgeleitet):

| Typ | Beispiel |
|-----|----------|
| `string` | `"Grippe"`, `'Husten'` |
| `number` | `42`, `36.6` |
| `boolean` | `true`, `false` |
| `undefined` | Variable ohne Wert |
| `null` | bewusst "kein Wert" |
| `object` | `{ name: "Anna" }` (siehe Kapitel 05.2) |
| `array` | `["Anna", "Bernd"]` |

Den Typ kannst du mit `typeof` abfragen:

```js
console.log(typeof "Grippe");   // string
console.log(typeof 42);         // number
```

## Ausgabe und Eingabe

| Funktion | Wirkung |
|----------|---------|
| `console.log(wert)` | Ausgabe in die DevTools-Konsole |
| `alert(text)` | Meldungsfenster |
| `prompt(text)` | Eingabe über Dialogfenster (für Übungen) |
| `document.write` | (veraltet – nicht verwenden) |

```js
let name = prompt("Name des Patienten:");
alert("Hallo " + name);
```

## Operatoren

```js
let first = 8;
let second = first + 2;      // 10
let quotient = first / 2;    // 4
let rest = first % 3;        // 2 (Modulo)
```

| Operator | Bedeutung |
|----------|-----------|
| `+` `-` `*` `/` | Grundrechenarten |
| `%` | Modulo (Rest) |
| `==` `===` | Vergleich (siehe unten) |
| `&&` `\|\|` `!` | und, oder, nicht |
| `+=` | `x = x + ...` Kurzform |

> Wichtig: `===` vergleicht **Wert und Typ**, `==` nur den Wert. Verwende immer `===`.

## Strings: Variablenwerte einbetten (Template Literals)

Mit **Template Literals** (Backticks) kannst du Variablen direkt in Text einbetten:

```js
let name = "Anna Maier";
let room = 102;

console.log(`Patient ${name} liegt im Zimmer ${room}.`);
// Patient Anna Maier liegt im Zimmer 102.
```

Die Schreibweise `${...}` fügt den Variablenwert in den Text ein – das entspricht `f-strings` aus Python.

## Funktionen

### Klassische Funktion

```js
function getBodyTemperature(unit) {
    return 36.6;
}
```

### Funktion mit Parametern

```js
function calculateBmi(weightKg, heightM) {
    return weightKg / (heightM * heightM);
}

let bmi = calculateBmi(70, 1.75);
console.log(bmi);   // 22.86
```

## Zusammenfassung

### Wichtige Begriffe
- `script`-Tag, externe JS-Datei
- `let`, `const`, dynamische Typisierung
- Datentypen: `string`, `number`, `boolean`, `object`, `array`
- `console.log`, `alert`, `prompt`
- Template Literals mit `${...}`
- Funktionen, `===`, `&&`/`||`

### Das sollst du können
- JavaScript in HTML einbinden
- Variablen deklarieren und Werte ausgeben
- Einfache Funktionen schreiben
- Variablenwerte mit Template Literals in Text einbetten
