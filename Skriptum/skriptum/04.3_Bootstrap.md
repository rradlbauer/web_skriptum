# 04.3 CSS – Frameworks (Bootstrap)

Anstatt jedes Styling von Grund auf selbst zu schreiben, verwenden Webentwickler*innen häufig **CSS-Frameworks**. Das bekannteste ist **Bootstrap**.

## Was ist ein CSS-Framework?

Ein **CSS-Framework** ist eine **Sammlung fertiger CSS-Regeln (und oft JavaScript-Bausteine)**, die du in dein Projekt einbinden kannst. Du musst dann nicht jede Klasse selbst schreiben, sondern verwendest vordefinierte Klassen für Layout, Buttons, Tabellen, Formulare usw.

Vorteile:
- Weniger CSS-Code selbst schreiben
- Einheitliches, fertiges Design
- Responsive Layouts oft "eingebaut"
- Gut dokumentiert und weit verbreitet

Nachteile:
- Viele Klassen im HTML (weniger sauberer HTML-Code)
- Das Design sieht schnell "typisch Bootstrap" aus

## Bootstrap einbinden

Bootstrap wird per `<link>` (CSS) und optional per `<script>` (JavaScript) eingebunden – meist über ein **CDN** (Content Delivery Network):

```html
<head>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
          rel="stylesheet">
</head>
<body>
    ...
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
```

> Wichtig: Für die Arbeit **ohne Internet** (z. B. in der Übungsumgebung) kannst du die CSS-Datei auch lokal in dein Projekt kopieren und einbinden.

## Das Grid-System von Bootstrap

Bootstrap verwendet ein **zwölfspaltiges Raster**. Mit den Klassen `col`, `col-4` usw. legst du fest, wie viele Spalten ein Element belegt:

```html
<div class="container">
    <div class="row">
        <div class="col-4">Patientendaten</div>
        <div class="col-4">Diagnose</div>
        <div class="col-4">Medikation</div>
    </div>
</div>
```

- `container`: zentrierter Container mit festen Rändern
- `row`: eine Zeile des Rasters
- `col-4`: ein Drittel der Breite (4 von 12 Spalten) auf allen Geräten

### Responsive Spalten

Du kannst Spalten **geräteabhängig** breit machen:

```html
<div class="col-md-6">...</div>
```

- `col-6` – immer halbe Breite
- `col-md-6` – ab der "md"-Größe (ab 768 px) halbe Breite, auf kleineren Geräten volle Breite

Breakpoints von Bootstrap: `sm` (≥576), `md` (≥768), `lg` (≥992), `xl` (≥1200).

## Wichtige Bootstrap-Klassen

| Klasse | Wirkung |
|--------|---------|
| `btn`, `btn-primary`, `btn-danger` | Buttons, farbig |
| `table`, `table-striped`, `table-hover` | Tabellen, zebragestreift, hover |
| `card` | Karte mit Rahmen/Schatten |
| `form-control` | formatiertes Eingabefeld |
| `alert alert-success` | Hinweisbox |
| `text-center`, `mt-3`, `p-2` | Abstände und Ausrichtung |

### Beispiel: Buttons und Tabelle

```html
<button class="btn btn-primary">Patient speichern</button>
<button class="btn btn-danger">Löschen</button>

<table class="table table-striped">
    <tr>
        <th>Name</th>
        <th>Diagnose</th>
    </tr>
    <tr>
        <td>Anna Maier</td>
        <td>Grippe</td>
    </tr>
</table>
```

### Beispiel: Karte (Card)

```html
<div class="card" style="width: 300px;">
    <div class="card-body">
        <h5 class="card-title">Anna Maier</h5>
        <p class="card-text">Diagnose: Grippe</p>
        <a href="#" class="btn btn-primary">Details</a>
    </div>
</div>
```

## Zusammenspiel mit deinem eigenen CSS

Bootstrap bietet die Grundgestaltung; für spezielle eigene Stile schreibst du **zusätzlich** deine eigene CSS-Datei und bindest sie **nach** Bootstrap ein:

```html
<link href="bootstrap.min.css" rel="stylesheet">
<link href="styles.css" rel="stylesheet">
```

## Zusammenfassung

### Wichtige Begriffe
- CSS-Framework, Bootstrap, CDN
- Grid-System (12 Spalten): `container`, `row`, `col`
- Klassen: `btn`, `table`, `card`, `form-control`
- Breakpoints: `sm`, `md`, `lg`, `xl`

### Das sollst du können
- Bootstrap in eine HTML-Seite einbinden
- Mit dem Bootstrap-Grid ein responsives Layout bauen
- Wichtige Klassen für Buttons, Tabellen und Karten einsetzen
