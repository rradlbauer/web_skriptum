# 07.2 TypeScript – Tabellen, Listen & Select-Boxen befüllen

Ein zentraler Ablauf in Web-Applikationen ist es, **Daten** (z. B. von einer API) in **Tabellen**, **Listen** und **Select-Boxen** darzustellen. In diesem Kapitel siehst du die Muster aus Kapitel 06.x in **typisierter** TypeScript-Variante.

## Grundprinzip: Elemente dynamisch erzeugen

Mit `document.createElement` erzeugst du Elemente zur Laufzeit. TypeScript kennt die genauen Elementtypen:

```ts
const li: HTMLLIElement = document.createElement("li");
li.textContent = "Anna Maier";

const liste = document.getElementById("doctorList") as HTMLUListElement;
liste.appendChild(li);
```

| erzeugt | Typ |
|---------|-----|
| `<tr>` | `HTMLTableRowElement` |
| `<td>` | `HTMLTableCellElement` |
| `<li>` | `HTMLLIElement` |
| `<option>` | `HTMLOptionElement` |

## Eine Tabelle befüllen

Zuerst ein **Interface** für die Daten – genau wie die JSON-Antwort einer API aussehen wird:

```ts
interface Patient {
    name: string;
    diagnosis: string;
}
```

HTML:

```html
<table id="patientTable">
    <tr>
        <th>Name</th>
        <th>Diagnose</th>
    </tr>
</table>
```

TypeScript:

```ts
const patients: Patient[] = [
    { name: "Anna Maier", diagnosis: "Grippe" },
    { name: "Bernd Huber", diagnosis: "Migräne" }
];

const table = document.getElementById("patientTable") as HTMLTableElement;

for (let patient of patients) {
    const row: HTMLTableRowElement = document.createElement("tr");

    const nameCell: HTMLTableCellElement = document.createElement("td");
    nameCell.textContent = patient.name;

    const diagnosisCell: HTMLTableCellElement = document.createElement("td");
    diagnosisCell.textContent = patient.diagnosis;

    row.appendChild(nameCell);
    row.appendChild(diagnosisCell);
    table.appendChild(row);
}
```

Der Ablauf pro Datensatz:
1. `tr` erzeugen (`HTMLTableRowElement`)
2. je Spalte ein `td` erzeugen und mit `textContent` füllen
3. `td`-Elemente in die `tr` hängen
4. `tr` an die Tabelle hängen

> Die Kopfzeile (`th`) bleibt stehen; es kommen nur die Datenzeilen (`tr`) dazu.

## Eine Liste befüllen

```ts
const doctors: string[] = ["Dr. Berg", "Dr. Feld", "Dr. Hall"];

const list = document.getElementById("doctorList") as HTMLUListElement;

for (let name of doctors) {
    const li: HTMLLIElement = document.createElement("li");
    li.textContent = name;
    list.appendChild(li);
}
```

## Eine Select-Box befüllen

```html
<select id="wardSelect"></select>
```

```ts
interface Ward {
    value: string;
    label: string;
}

const wards: Ward[] = [
    { value: "inne", label: "Innere Medizin" },
    { value: "chir", label: "Chirurgie" },
    { value: "paed", label: "Pädiatrie" }
];

const select = document.getElementById("wardSelect") as HTMLSelectElement;

for (let ward of wards) {
    const option: HTMLOptionElement = document.createElement("option");
    option.value = ward.value;
    option.textContent = ward.label;
    select.appendChild(option);
}
```

Für jede Station wird eine `<option>` erzeugt, deren `value` und Anzeigetext gesetzt werden.

## Tabelle vorher leeren

Damit doppelte Zeilen beim erneuten Aufruf nicht entstehen, leerst du zuerst den Datenbereich:

```ts
function clearTableRows(table: HTMLTableElement): void {
    const rows = table.querySelectorAll("tr");
    for (let i = 1; i < rows.length; i++) {  // Kopfzeile bleibt
        rows[i].remove();
    }
}
```

## Alternative: mit `innerHTML` (mit Vorsicht)

Für einfache Fälle kannst du Zeilen als HTML-String zusammenbauen:

```ts
table.innerHTML += `<tr><td>${patient.name}</td><td>${patient.diagnosis}</td></tr>`;
```

Das ist kürzer, aber **gefährlich bei Benutzereingaben** (XSS, Kapitel 07.0). `createElement` + `textContent` ist sicherer und wird hier bevorzugt.

## Beispiel als Funktion

```ts
function renderPatientTable(patients: Patient[], tableId: string): void {
    const table = document.getElementById(tableId) as HTMLTableElement;
    clearTableRows(table);

    for (let patient of patients) {
        const row: HTMLTableRowElement = document.createElement("tr");

        const nameCell: HTMLTableCellElement = document.createElement("td");
        nameCell.textContent = patient.name;
        row.appendChild(nameCell);

        const diagnosisCell: HTMLTableCellElement = document.createElement("td");
        diagnosisCell.textContent = patient.diagnosis;
        row.appendChild(diagnosisCell);

        table.appendChild(row);
    }
}

renderPatientTable(patients, "patientTable");
```

## Zusammenfassung

### Wichtige Begriffe
- `createElement` mit konkreten Typen (`HTMLTableRowElement`, `HTMLTableCellElement`, `HTMLLIElement`, `HTMLOptionElement`)
- `appendChild`
- Interface für Daten (`Patient[]`, `Ward[]`)
- Tabelle leeren, `innerHTML` vs. `textContent`

### Das sollst du können
- Tabellen-Zeilen aus einem typisierten Array von Objekten erzeugen
- Listen und Select-Boxen dynamisch befüllen
- Eine Tabelle vor dem Neubefüllen leeren
