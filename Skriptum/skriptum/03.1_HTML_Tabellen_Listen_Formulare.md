# 03.1 HTML – Tabellen, Listen & Formulare

In diesem Kapitel lernst du die HTML-Elemente, mit denen du **Tabellen**, **Listen** und **Formulare** erstellst. Diese spielen in Web-Applikationen – etwa einer Patientenverwaltung – eine zentrale Rolle.

## Listen

Es gibt zwei Grundformen von Listen:

### Ungeordnete Liste (`<ul>`)

```html
<h2>Symptome</h2>
<ul>
    <li>Fieber</li>
    <li>Husten</li>
    <li>Müdigkeit</li>
</ul>
```

### Geordnete Liste (`<ol>`)

```html
<h2>Behandlungsschritte</h2>
<ol>
    <li>Diagnose stellen</li>
    <li>Medikation festlegen</li>
    <li>Nachkontrolle planen</li>
</ol>
```

- `<ul>`: unordered list – Punkte ohne Nummerierung
- `<ol>`: ordered list – nummerierte Punkte
- `<li>`: list item – ein einzelner Punkt

## Tabellen

Eine Tabelle wird mit `table`, `tr` (Zeile), `th` (Zellenkopf) und `td` (Zelle) aufgebaut:

```html
<table>
    <tr>
        <th>Name</th>
        <th>Diagnose</th>
        <th>Zimmer</th>
    </tr>
    <tr>
        <td>Anna Maier</td>
        <td>Grippe</td>
        <td>102</td>
    </tr>
    <tr>
        <td>Bernd Huber</td>
        <td>Migration</td>
        <td>105</td>
    </tr>
</table>
```

| Element | Bedeutung |
|---------|-----------|
| `<table>` | Tabelle |
| `<tr>` | table row – eine Zeile |
| `<th>` | table header – Zellenkopf (fett) |
| `<td>` | table data – eine Datenzelle |

## Formulare

Ein **Formular** (`<form>`) dient dazu, **Eingaben** des Benutzers zu sammeln und zu übermitteln (z. B. an einen Server).

```html
<form action="/api/patients" method="post">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name"><br>

    <label for="age">Alter:</label>
    <input type="number" id="age" name="age"><br>

    <label for="diagnosis">Diagnose:</label>
    <input type="text" id="diagnosis" name="diagnosis"><br>

    <button type="submit">Speichern</button>
</form>
```

### Wichtige Formular-Elemente

| Element / Typ | Verwendung |
|----------------|------------|
| `<input type="text">` | einzeiliges Textfeld |
| `<input type="number">` | Zahlenfeld |
| `<input type="password">` | Passwortfeld (verdeckt) |
| `<input type="checkbox">` | Ankreuzfeld |
| `<input type="radio">` | Auswahl (ein von mehreren) |
| `<textarea>` | mehrzeiliges Textfeld |
| `<select>` / `<option>` | Dropdown-Auswahl |
| `<button type="submit">` | Absenden-Button |

### Das Attribut `name`

Das Attribut `name` des Eingabefelds ist wichtig: Es bestimmt den **Schlüssel**, unter dem der Wert beim Absenden übertragen wird. Aus `name="name"` mit Wert `Anna` wird z. B. `name=Anna`.

### `<select>` mit `<option>`

```html
<label for="ward">Station:</label>
<select id="ward" name="ward">
    <option value="inne">Innere Medizin</option>
    <option value="chir">Chirurgie</option>
    <option value="päd">Pädiatrie</option>
</select>
```

### Checkbox und Radio

```html
<p>Ist der Patient versichert?</p>
<input type="checkbox" id="insured" name="insured" value="yes">
<label for="insured">versichert</label>
```

Radio-Buttons gruppiert man über denselben `name`:

```html
<p>Geschlecht:</p>
<input type="radio" id="w" name="gender" value="w">
<label for="w">weiblich</label>
<input type="radio" id="m" name="gender" value="m">
<label for="m">männlich</label>
```

## Label und IDs

Ein `<label>` beschriftet ein Eingabefeld. Über das Attribut `for` (mit derselben `id` wie das Element) kannst du das Label mit dem Feld verknüpfen – ein Klick auf das Label aktiviert das Feld.

## Zusammenfassung

### Wichtige Begriffe
- `<ul>`, `<ol>`, `<li>`
- `<table>`, `<tr>`, `<th>`, `<td>`

- Attribute `name`, `id`, `for`, `value`, `type`

### Das sollst du können
- Listen und Tabellen in HTML erstellen
- Ein Formular mit den wichtigsten Eingabeelementen aufbauen
- Die Funktion der Attribute `name`, `id` und `for` erklären
