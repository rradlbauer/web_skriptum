# 00.0 Über dieses Skriptum

Dieses Skriptum begleitet den Einstieg in die **Webentwicklung** und die Erstellung von **Web-Applikationen**.

Es setzt die Kenntnisse aus dem **Java-Skriptum** voraus, insbesondere die Grundlagen von Java, Objektorientierung (OOP), Collections, JDBC/JPA und die Grundlagen von **Spring Boot**. Dieses Skriptum baut darauf auf und erweitert den Blick um die Client-Seite: HTML, CSS und JavaScript sowie die Kommunikation zwischen Browser (Client) und Server.

## Aufbau

Jedes Kapitel enthält:

- Erklärungen mit Code-Beispielen
- Übungsaufgaben
- Eine Zusammenfassung der wichtigsten Begriffe

## Konventionen

- Code-Beispiele werden mit Syntax-Highlighting dargestellt
- Wichtige Begriffe sind **fett** hervorgehoben
- Code, Dateinamen und Pfade werden in `Code-Schriftart` dargestellt
- Die Sprache der Texte ist **Deutsch**
- Die Sprache im Code (Bezeichner, Variablen, Funktionen, Klassen) ist **Englisch** – so bleibt der Code unabhängig von der Dokumentationssprache verständlich

## Medizinisches Thema

Beispiele und Übungen verwenden nach Möglichkeit ein **medizinisches Thema** (Patienten, Ärzt*innen, Diagnosen, Medikamente, Impfungen, Laborwerte, ...). So bleibt das Skriptum anschaulich und ein Beispielprojekt – eine **Patientenverwaltung** – zieht sich durch viele Kapitel.

## Übungen

Die Übungen befinden sich im Ordner `uebungen/`. Sie sind nach dem Schema `UE_XX.Y_Thema.md` benannt und vertiefen den Stoff des jeweiligen Kapitels.

## Voraussetzungen

- Kenntnisse aus dem Java-Skriptum (OOP, Collections, JDBC/JPA, Spring Boot-Grundlagen)
- Grundlegendes Verständnis von Datenbanken und HTTP wird hilfreich sein
- Ein moderner Browser (Chrome, Firefox, Edge) und ein Texteditor / eine IDE (VS Code)
