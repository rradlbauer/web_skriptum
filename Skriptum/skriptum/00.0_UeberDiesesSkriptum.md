# 00.0 – Über dieses Skriptum

## Ziel

In diesem Skriptum entwickelt ihr gemeinsam eine Web-Applikation namens **Clinical Diary** – ein digitales Patienten-Tagebuch, mit dem Patienten ihre Gesundheitsdaten verwalten und Ärzte diese bestätigen und kommentieren können.

Der Schwerpunkt liegt auf der **praktischen Umsetzung** mit modernen Web-Technologien.

## Für wen ist dieses Skriptum?

Das Skriptum richtet sich an Studierende mit folgenden **Vorkenntnissen**:

- **Java & OOP**: Klassen, Vererbung, Interfaces, Generics
- **Grundlagen JPA**: `@Entity`, `@Id`, `@OneToMany` usw.
- **Spring Boot mit Thymeleaf**: Controller, Repositories, serverseitiges Rendering
- **HTML & CSS**: Semantisches HTML, Layouts

## Was ist neu?

Bisher habt ihr mit **Thymeleaf** serverseitig gerendert – der Server hat HTML generiert und direkt an den Browser geschickt. In diesem Skriptum arbeitet ihr mit einer anderen Architektur:

| Bisher (Thymeleaf) | Hier (REST API + SPA) |
|---------------------|----------------------|
| Server generiert HTML | Browser generiert HTML |
| Seiten werden bei jedem Klick neu geladen | Nur Daten werden geladen (AJAX) |
| Session/Cookie für Authentifizierung | JWT Token für Authentifizierung |
| Thymeleaf-Templates | TypeScript Single-Page Application |

Der Browser wird eigenständig – er baut die Oberfläche selbst aus JSON-Daten. Das nennt man **client-side rendering**.
