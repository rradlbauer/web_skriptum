# 07.1 TypeScript – Formulare auslesen & befüllen

Formulare sind die wichtigste Schnittstelle zur **Eingabe** von Daten durch Benutzer*innen. In diesem Kapitel lernst du, wie du Formularwerte mit **TypeScript** **ausliest** und Formulare **befüllt** – dieselben Techniken wie in Kapitel 06.x, aber mit Typsicherheit.

## Auslesen von Formular-Daten

Für jedes Eingabefeld greifst du über die `id` auf das Element zu und liest mit `.value` den aktuellen Wert. TypeScript verlangt zwei Dinge:

1. den **`null`-Fall** berücksichtigen (Element kann fehlen)
2. den **konkreten Typ** angeben (`as HTMLInputElement`)

```html
<form id="patientForm">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name">

    <label for="age">Alter:</label>
    <input type="number" id="age" name="age">

    <button type="submit" id="save">Speichern</button>
</form>
```

```ts
const nameInput = document.getElementById("name") as HTMLInputElement;
const ageInput = document.getElementById("age") as HTMLInputElement;

console.log(nameInput.value);   // aktueller Wert
```

### Der komplette Ablauf beim Absenden

```ts
const form = document.getElementById("patientForm") as HTMLFormElement;

form.addEventListener("submit", (event: Event) => {
    event.preventDefault();     // Neuladen der Seite verhindern

    const name = (document.getElementById("name") as HTMLInputElement).value;
    const age = (document.getElementById("age") as HTMLInputElement).value;

    console.log(`Name: ${name}, Alter: ${age}`);
});
```

`event.preventDefault()` verhindert das **Neu laden** der Seite, das ein Formular standardmäßig auslöst – sonst könnte TypeScript die Daten nicht weiterverarbeiten.

## Formular als typisiertes Objekt sammeln

Statt `const patient = {...}` ohne Typ verwendest du ein **Interface** (aus Kapitel 06.0). Das ist genau die Datenform, die später als JSON an die REST-API geht (Kapitel 07.4):

```ts
interface PatientFormData {
    name: string;
    age: number;
    ward: string;
    notes: string;
}

form.addEventListener("submit", (event: Event) => {
    event.preventDefault();

    const patient: PatientFormData = {
        name: (document.getElementById("name") as HTMLInputElement).value,
        age: Number((document.getElementById("age") as HTMLInputElement).value),
        ward: (document.getElementById("ward") as HTMLSelectElement).value,
        notes: (document.getElementById("notes") as HTMLTextAreaElement).value
    };

    console.log(JSON.stringify(patient));
});
```

Beachte: `.value` ist immer ein **String**. Für ein Zahlenfeld wandelst du mit `Number(...)` um – so stimmt der Typ der Variable mit dem Interface überein.

### Werte anderer Elementtypen

```ts
// select / dropdown
const select = document.getElementById("ward") as HTMLSelectElement;
const ward: string = select.value;

// checkbox
const checkbox = document.getElementById("insured") as HTMLInputElement;
const insured: boolean = checkbox.checked;

// radio (gruppiert über denselben name)
const genderInput = document.querySelector(
    'input[name="gender"]:checked'
) as HTMLInputElement;
const gender: string = genderInput.value;

// textarea
const textarea = document.getElementById("notes") as HTMLTextAreaElement;
const notes: string = textarea.value;
```

Checkboxen verwenden `.checked` (boolean), Text- und Auswahlfelder `.value`.

> Tipp: Schreibe dir kleine **Hilfsfunktionen**, damit die `as`-Angaben nicht überall doppelt stehen:

```ts
function inputValue(id: string): string {
    return (document.getElementById(id) as HTMLInputElement).value;
}

const name: string = inputValue("name");
```

## Befüllen von Formularen

Umgekehrt befüllst du Formularfelder per TypeScript – z. B. wenn du gespeicherte Daten wiederherstellst (Kapitel 07.3) oder Daten von einer API lädst:

```ts
interface PatientFormData {
    name: string;
    age: number;
    ward: string;
    notes: string;
}

function fillPatientForm(patient: PatientFormData): void {
    (document.getElementById("name") as HTMLInputElement).value = patient.name;
    (document.getElementById("age") as HTMLInputElement).value = String(patient.age);
    (document.getElementById("ward") as HTMLSelectElement).value = patient.ward;
    (document.getElementById("notes") as HTMLTextAreaElement).value = patient.notes;
}
```

```ts
const patient: PatientFormData = {
    name: "Anna Maier",
    age: 42,
    ward: "inne",
    notes: "Befund ausstehend"
};

fillPatientForm(patient);
```

## Ein Beispiel: Formular von einem Objekt befüllen

```html
<button id="loadDemo">Demo-Daten laden</button>
```

```ts
const loadButton = document.getElementById("loadDemo") as HTMLButtonElement;

loadButton.addEventListener("click", () => {
    const demoPatient: PatientFormData = {
        name: "Bernd Huber",
        age: 55,
        ward: "chir",
        notes: "Befund ausstehend"
    };
    fillPatientForm(demoPatient);
});
```

## Zusammenfassung

### Wichtige Begriffe
- `HTMLFormElement`, `HTMLInputElement`, `HTMLSelectElement`, `HTMLTextAreaElement`
- `as`-Typ-Assertion, `null`-Handling
- `event: Event`, `event.preventDefault()`
- Interface für Formulardaten, `Number(...)`-Umwandlung
- Formulare befüllen über `.value = ...`

### Das sollst du können
- Formulardaten typisiert auslesen und in einem Interface-Objekt bündeln
- Das Neuladen der Seite beim Absenden verhindern
- Formularfelder programmatisch befüllen (auch `select`, `textarea`)
