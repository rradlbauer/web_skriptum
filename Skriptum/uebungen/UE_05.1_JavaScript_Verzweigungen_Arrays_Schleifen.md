### UE_05.1_1: Verzweigung Fieber

1. Schreibe eine Funktion `classifyTemperature(temp)`:

   - `>= 39`: "hohes Fieber"
   - `>= 38`: "Fieber"
   - `>= 37`: "leicht erhöht"
   - sonst: "normal"

2. Teste die Funktion mit den Werten `36.1`, `37.5`, `38.8`, `39.5`.

### UE_05.1_2: Array-Operationen

1. Erstelle ein Array `medications` mit drei Medikamenten.
2. Füge mit `push` ein viertes hinzu und gib die Länge aus.
3. Prüfe mit `includes`, ob "Aspirin" enthalten ist.
4. Gib das Array mit `join(", ")` als Text aus.

### UE_05.1_3: Schleifen

1. Schreibe eine `for`-Schleife von 0 bis 4 und gib `"Patient <i>"` aus.
2. Schreibe eine `for...of`-Schleife über `medications`.
3. Schreibe eine `while`-Schleife, die 3 Versuche ausgibt.

### UE_05.1_4: Triage

1. Schreibe die Funktion `triage(heartRate)` aus dem Kapitel selbst nach.
2. Filtere aus dem Array `[55, 72, 110, 95]` mit `filter` alle Werte heraus, die im "normalen" Bereich liegen (60–100).
3. Erkläre die Pfeilfunktion `p => ...` in eigenen Worten (verglichen mit einem Lambda aus dem Java-Skriptum).

### UE_05.1_5: switch

1. Schreibe eine `switch`-Anweisung, die eine Station codiert (`A`, `B`, `C`) in den Namen "Innere", "Chirurgie", "Pädiatrie" umsetzt.
2. Was passiert, wenn du `break` weglässt? Erkläre an einem Beispiel.
