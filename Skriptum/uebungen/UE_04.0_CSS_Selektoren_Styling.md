# UE_04.0 CSS – Selektoren & Styling – Übungen

[<<](../skriptum/04.0_CSS_Selektoren_Styling.md)

### UE_04.0_1: CSS einbinden

1. Erstelle eine HTML-Datei `patienten.html` und eine externe CSS-Datei `styles.css`.
2. Binde die CSS-Datei über `<link>` im `<head>` der HTML-Datei ein.
3. Erkläre den Vorteil einer externen CSS-Datei gegenüber Inline-Styles.

Füge dann für die nächsten Übungen in `patienten.html` folgende Inhalte ein:
* mindestens eine `h1`-Überschrift
* mindestens eine `h2`-Überschrift
* mindestens ein `div` mit Klasse `karte`
* ein `div` mit id `navi`
* ein `<main>` und darin mehrere Absätze (`p`)
* einen Absatz (`p`) mit Klasse `text`
* einen Absatz (`p`) mit Klasse `text` und id `special`

### UE_04.0_2: Selektoren

Erstelle in `styles.css` folgende Regeln:

1. Element-Selektor: alle `<h1>` in der Farbe blau, alle `<h2>` in Farbe grün
2. Klassen-Selektor: `.karte` mit Rahmen, Innenabstand und Hintergrundfarbe
3. ID-Selektor: `#navi` mit Hintergrundfarbe und weißer Schrift
4. Nachfahren-Selektor: alle `<p>` innerhalb von `<main>` mit `font-size: 14px`

### UE_04.0_3: Styling-Eigenschaften

1. Gestalte die `.karte` zusätzlich mit `border-radius`, `margin` und `padding`.
2. Erkläre den Unterschied zwischen `padding` und `margin`.
3. Teste die Wirkung von `padding: 16px` und `margin: 16px` an einem Element.

### UE_04.0_4: Spezifität

Gegeben sei:

```css
p { color: blue; }
.text { color: green; }
#special { color: red; }
```

1. Welche Farbe hat ein `<p>` mit `class="text"`? Begründe.
2. Welche Farbe hat ein `<p id="special" class="text">`? Begründe.
3. Was passiert bei Inline-Styles? Warum?

### UE_04.0_5: Diagnosekarten

Erstelle die Datei `diagnosen.css`, um diese Seite schön zu gestalten.
(Verwende gegebenenfalls ein KI-Tool).
Füge in die CSS-Datei ausreichend Kommentare, so dass du jede einzelne
Zeile erklären kannst.

``` html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Patients</title>
    <link href="diagnosen.css" rel="stylesheet">
</head>
<body>
    <nav>
        <a href="#patient1">Max Mustermann</a>
        <a href="#patient2">Erika Mustermitglied</a>
        <a href="#patient3">John Doe</a>
    </nav>
    <h1>Patienten</h1>
    <header>
        Alle Patienten sind frei erfunden, und auch die Diagnosen sollte man nicht allzu ernst nehmen!
    </header>
    <main>
        <div class="karte" id="patient1">
            <h2>Name</h2>
            Max Mustermann
            <h2>Diagnose</h2>
            <p>
                Der Patient zeigt eine <span class="wichtig">kritische Überlastung</span> der 
                kognitiven Pufferzonen, ausgelöst durch ununterbrochenen Konsum von Tabellenkalkulationen 
                und unstrukturierten Quelltexten.
            </p>
            <p>
                Es liegt eine temporäre Asynchronität der Synapsen vor. 
                Dies führt zu einer spürbaren Verlangsamung der manuellen Tippgeschwindigkeit sowie zu spontanem, 
                unkontrolliertem Augenrollen bei Erwähnung von Fristen.
            </p>
        </div>
        <div class="karte" id="patient2">
            <h2>Name</h2>
            Erika Mustermitglied
            <h2>Diagnose</h2>
            <p>
                Die Patientin leidet unter einer <span class="wichtig">kritischen Phrasen-Intoxikation</span>, 
                hervorgerufen durch die Teilnahme an aufeinanderfolgenden, ergebnisbefreiten Videokonferenzen.
            </p>
            <p>
                Es zeigt sich eine ausgeprägte Resistenz gegen Buzzwords. 
                Dies führt zu chronischer Taubheit bei den Begriffen „Synergie“ und „Agilität“ sowie zu 
                spontanen Fluchtreflexen beim Ertönen des Outlook-Benachrichtigungstons.
            </p>
        </div>
        <div class="karte" id="patient3">
            <h2>Name</h2>
            John Doe
            <h2>Diagnose</h2>
            <p>
                Der Patient weist eine <span class="wichtig">kritische Dehydrierung</span> des 
                Koffein-Kreislaufs auf, verursacht durch eine defekte Kaffeemaschine im Aufenthaltsraum.
            </p>
            <p>
                Diagnostiziert wurde ein kritischer Mangel an Betriebsenergie. 
                Dies äußert sich in einer verringerten Reaktionszeit auf direkte Fragen, permanentem 
                Starren auf leere Tassen und einer temporären Unfähigkeit, freundliche Begrüßungen zu formulieren.
            </p>
        </div>
    </main>
    <footer>
        &#169; Dr. Nobody
    </footer>
</body>
</html>
```
