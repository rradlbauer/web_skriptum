### UE_04.0_1: CSS einbinden

1. Erstelle eine HTML-Datei `patienten.html` und eine externe CSS-Datei `styles.css`.
2. Binde die CSS-Datei über `<link>` im `<head>` der HTML-Datei ein.
3. Erkläre den Vorteil einer externen CSS-Datei gegenüber Inline-Styles.

### UE_04.0_2: Selektoren

Erstelle in `styles.css` folgende Regeln:

1. Element-Selektor: alle `<h1>` in der Farbe `#2c3e50`
2. Klassen-Selektor: `.karte` mit Rahmen, Innenabstand und Hintergrundfarbe
3. ID-Selektor: `#navi` mit Hintergrundfarbe und weißer Schrift
4. Nachfahren-Selektor: alle `<p>` innerhalb von `<main>` mit `font-size: 14px`

### UE_04.0_3: Styling-Eigenschaften

1. Gestalte die `.karte` zusätzlich mit `border-radius`, `margin` und `padding`.
2. Erkläre den Unterschied zwischen `padding` und `margin`.
3. Teste die Wirkung von `padding: 16px` und `margin: 16px` an einem Element.

### UE_04.0_4: Spezifität

Gegeben sei:

```css
p { color: blue; }
.text { color: green; }
#special { color: red; }
```

1. Welche Farbe hat ein `<p>` mit `class="text"`? Begründe.
2. Welche Farbe hat ein `<p id="special" class="text">`? Begründe.
3. Was passiert bei Inline-Styles? Warum?
