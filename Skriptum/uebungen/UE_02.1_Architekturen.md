### UE_02.1_1: SSR oder CSR?

Ordne zu: SSR oder CSR?

1. Eine Spring-Boot-Anwendung liefert mit Thymeleaf eine fertige Patientenseite als HTML.
2. JavaScript lädt per `fetch` eine Liste von Laborwerten und baut eine Tabelle im Browser.
3. Eine React-App, die nur `index.html` lädt und die Ansichten client-seitig umschaltet.
4. Ein Server generiert pro Anfrage eine neue HTML-Seite.

### UE_02.1_2: Ablauf beschreiben

Beschreibe den vollständigen Ablauf für **CSR** am Beispiel "Liste der Diagnosen anzeigen":

1. Was wird zuerst geladen?
2. Welcher Request holt die Daten?
3. Wer erzeugt die Tabelle und in welchem Format kommen die Daten?

### UE_02.1_3: SPA verstehen

1. Erkläre, warum eine SPA nur aus einer HTML-Datei besteht und trotzdem viele "Seiten" (Ansichten) zeigen kann.
2. Nenne zwei Vor- und zwei Nachteile einer SPA gegenüber einer klassischen (SSR) Web-App.
3. Erkläre die Rolle der REST-API in einer SPA.

### UE_02.1_4: Schichten zuordnen

Ordne die Begriffe den Schichten zu: `Controller`, `Service`, `Repository`, `Browser`, `MySQL`.

1. Welche Schicht spricht direkt mit der Datenbank?
2. Welche Schicht enthält die Geschäftslogik?
3. In welcher Schicht läuft JavaScript (Client)?
4. Welche Schicht nimmt HTTP-Anfragen entgegen?
