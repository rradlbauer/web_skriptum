# UE_05.0 JavaScript-Grundlagen – Übungen

[<<](../skriptum/05.0_JavaScript_Grundlagen.md)

### UE_05.0_1: Einbindung und Konsole

1. Erstelle eine HTML-Seite `uebung.html` und binde eine externe Datei `script.js` ein.
2. Schreibe in `script.js` ein `console.log("JavaScript läuft!")`.
3. Öffne die Seite im Browser und prüfe die Ausgabe in der Konsole.

### UE_05.0_2: Variablen und Datentypen

1. Deklariere Variablen mit `let`/`const` für: Name (string), Alter (number), versichert (boolean).
2. Gib mit `console.log` und Template Literals aus: `"Anna Maier, 42 Jahre, versichert: true"`.
3. Teste `typeof` für alle drei Variablen.

### UE_05.0_3: BMI-Funktion

1. Schreibe eine Funktion `calculateBmi(weightKg, heightM)`, die den BMI berechnet (`gewicht / (groesse*höhe)`).
2. Rufe sie mit `calculateBmi(70, 1.75)` auf und gib das Ergebnis aus.
3. Erweitere die Ausgabe: `"BMI von Anna: 22.86"` (mit Template Literals).

### UE_05.0_4: Eingabe mit prompt

1. Frage mit `prompt` nach dem Namen und Alter eines Patienten.
2. Gib mit `alert` einen Satz mit beiden Werten aus (Template Literals).
3. Erkläre, warum `===` gegenüber `==` bevorzugt werden sollte.

### UE_05.0_5: const vs. let

1. Erkläre den Unterschied von `let` und `const`.
2. Was passiert, wenn du einer `const`-Variablen später einen neuen Wert zuweist?
3. Schreibe ein kurzes Beispiel, in dem `const` verwendet werden sollte (z. B. eine unveränderbare Dosierung).
