# UE_03.2 HTML – div, span & weitere wichtige Elemente – Übungen

[<<](../skriptum/03.2_HTML_div_span_Elemente.md)

### UE_03.2_1: Block vs. Inline

1. Erkläre den Unterschied zwischen einem Block-Element und einem Inline-Element.
2. Ordne folgende Elemente zu: `<div>`, `<span>`, `<p>`, `<a>`, `<h2>`, `<strong>`.
3. Erkläre, warum ein `<div>` innerhalb eines `<p>`-Absatzes kein gültiges (sinnvolles) Layout ergibt.

### UE_03.2_2: Patientenkarten

1. Erstelle drei "Patientenkarten" mit jeweils einem `<div class="karte">`.
2. Jede Karte enthält einen Namen und eine Diagnose.
3. Markiere in jeder Karte das Wort "Kritisch" (sofern vorkommend) mit `<span class="wichtig">`, damit es später hervorgehoben werden kann.

### UE_03.2_3: Semantische Struktur

1. Baue eine Seite mit folgenden semantischen Elementen auf: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`.
2. Platziere im `<nav>` drei Links (z. B. "Patienten", "Termine", "Medikamente").
3. Erkläre, welchen Vorteil semantische Elemente gegenüber reinen `div`-Elementen bieten.

### UE_03.2_4: class und id

1. Erkläre den Unterschied zwischen `class` und `id`.
2. Warum darf eine `id` nur einmal pro Seite vorkommen, eine `class` aber mehrfach?
3. Nenne ein Beispiel, bei dem du `class` verwendest, und eines, bei dem `id` sinnvoll ist.
