# Übungen zu 03.0 – JPA Entitäten & Spring Data Repositories

## UE_03.0_1 – Neue Entität "Appointment" erstellen

**Aufgabe**: Erstelle eine neue JPA-Entität `Appointment` für Termine zwischen Patienten und Ärzten.

### Anforderungen

1. Erstelle eine neue Datei `Appointment.java` im Package `com.clinicaldiary.entity`
2. Die Entität soll folgende Felder haben:

| Feld | Typ | Beschreibung |
|------|-----|-------------|
| `id` | `Long` | Primärschlüssel (auto-generiert) |
| `patientId` | `Long` | ID des Patienten (nicht nullable) |
| `doctorId` | `Long` | ID des Arztes (nicht nullable) |
| `date` | `String` | Terminzeitpunkt |
| `reason` | `String` | Grund des Termins |
| `status` | `String` | Status: "SCHEDULED", "COMPLETED", "CANCELLED" |

3. Verwende `@Entity`, `@Table(name = "appointments")`, `@Id`, `@GeneratedValue`
4. Erstelle einen Standard-Konstruktor und alle Getter/Setter

### Test

Starte die Anwendung und überprüfe in der H2-Konsole (`/h2-console`), ob die Tabelle `APPOINTMENTS` automatisch erstellt wurde.

## UE_03.0_2 – Repository für Appointment erstellen

**Aufgabe**: Erstelle ein Spring Data Repository für die `Appointment`-Entität.

### Anforderungen

1. Erstelle eine neue Datei `AppointmentRepository.java` im Package `com.clinicaldiary.repository`
2. Das Repository soll `JpaRepository<Appointment, Long>` implementieren
3. Füge folgende Query-Methoden hinzu:

```java
// Alle Termine eines Patienten, sortiert nach Datum (absteigend)
List<Appointment> findByPatientIdOrderByDateDesc(Long patientId);

// Alle Termine eines Arztes
List<Appointment> findByDoctorId(Long doctorId);

// Prüfen ob ein bestimmter Termin existiert
boolean existsByPatientIdAndDoctorIdAndDate(Long patientId, Long doctorId, String date);
```

### Bonus

Erstelle einen `AppointmentController` mit einem `GET`-Endpoint, der alle Termine eines Patienten zurückgibt.

## UE_03.0_3 – Feld hinzufügen und Datenbank-Schema überprüfen

**Aufgabe**: Füge der `Patient`-Entität ein neues Feld `phoneNumber` hinzu und überprüfe die Auswirkungen.

### Schritte

1. **Öffne** `Patient.java` und füge ein neues Feld hinzu:
   ```java
   private String phoneNumber;
   ```

2. **Füge** Getter und Setter hinzu:
   ```java
   public String getPhoneNumber() { return phoneNumber; }
   public void setPhoneNumber(String phoneNumber) { this.phoneNumber = phoneNumber; }
   ```

3. **Starte** die Anwendung neu

4. **Öffne** die H2-Konsole und führe aus:
   ```sql
   SELECT * FROM PATIENTS;
   ```

5. **Überprüfe**:
   - Enthält die Tabelle eine neue Spalte `PHONENUMBER`?
   - Sind die bestehenden Patientendaten noch vorhanden?
   - Was passiert, wenn du das Feld mit `@Column(nullable = false)` markierst?

### Reflexionsfrage
Was ist der Unterschied zwischen `create-drop` und `update` als `ddl-auto`-Strategie? Welche Konsequenzen hat das für die Entwicklung?
