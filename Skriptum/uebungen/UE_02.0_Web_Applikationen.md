### UE_02.0_1: statisch oder dynamisch?

Ordne zu und begründe: statisch oder dynamisch?

1. Eine fixe Info-Seite über die Öffnungszeiten der Ambulanz
2. Ein Patientenportal, das die eigenen Befunde je nach Benutzer anzeigt
3. Eine Webseite mit einer Tabelle der Arzneimittel
4. Ein Auslastungs-Dashboard für Krankenstationen

### UE_02.0_2: Webserver & Web-Service

1. Erkläre den Unterschied zwischen einem **Webserver** und einem **Web-Service** (Web-API).
2. Nenne den eingebauten Webserver von Spring Boot und die Standard-Adresse, unter der eine Spring-Boot-App erreichbar ist.
3. Angenommen, der Server antwortet auf `GET /api/patients` mit JSON. Ist das eher ein Webserver oder ein Web-Service? Begründe.

### UE_02.0_3: Client- vs. Server-seitig

Für jeden Fall: wird die Logik eher client- oder server-seitig ausgeführt?

1. Die Anzeige einer Fehlermeldung beim unvollständigen ausgefülltem Formular
2. Die Prüfung, ob eine eingegebene SV-Nummer bereits in der Datenbank existiert
3. Das Aktualisieren einer Tabelle ohne dass die Seite neu geladen wird

### UE_02.0_4: Bestandteile einer Web-App

1. Zeichne ein Diagramm einer dynamischen Web-Applikation mit den Teilen: Browser, Webserver, Anwendung (Spring Boot), Datenbank (MySQL).
2. Zeichne die Kommunikation zwischen den Komponenten als Pfeile ein
3. Beschrifte die Pfeile mit `HTTP`, `SQL` bzw. `JSON`.
3. Erkläre kurz, warum die Datenbank nicht direkt mit dem Browser spricht.
