### UE_00.1_1: DevTools erkunden

1. Öffne eine beliebige Webseite (z. B. spengergasse.at) und öffne die DevTools (`F12`).
2. Wechsle in den Bereich **Elements** und markiere ein Element – wo wird die zugehörige CSS-Datei angezeigt?
3. Wechsle in den Bereich **Network** und lade die Seite neu. Nenne mindestens drei verschiedene Ressourcen, die geladen werden (z. B. HTML, CSS, Bild, JavaScript).

### UE_00.1_2: Konsolenausgabe

1. Öffne die Konsole der DevTools.
2. Gib `console.log("Hello from DevTools");` ein und bestätige mit Eingabe.
3. Erkläre, wofür `console.log()` in JavaScript verwendet wird – wo erscheint die Ausgabe?

### UE_00.1_3: VS Code & Live Server

1. Erstelle einen Ordner `web_uebung` auf deinem Rechner.
2. Lege darin eine Datei `index.html` mit dem Inhalt `<!DOCTYPE html><html><body><h1>Hallo</h1></body></html>` an.
3. Öffne den Ordner in VS Code und starte **Live Server**.
4. Rufe die Seite im Browser unter `http://localhost:5500` (oder dem angezeigten Port) auf und notiere die Adresse.
5. Erkläre den Unterschied zwischen `file://.../index.html` und `http://localhost:5500/index.html`.
