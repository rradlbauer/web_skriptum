# Übungen zu 05.1 – Single-Page Application mit TypeScript

## UE_05.1_1 – Minimale SPA mit zwei Views

**Aufgabe**: Erstelle eine minimale Single-Page Application, die zwischen zwei Views (Home und About) wechseln kann, ohne die Seite neu zu laden.

### Schritte

1. **Erstelle eine neue HTML-Datei** `spa-minimal.html`:

```html
<!DOCTYPE html>
<html lang="de">
<head>
    <meta charset="UTF-8">
    <title>Minimale SPA</title>
    <style>
        body { font-family: sans-serif; max-width: 600px; margin: 2rem auto; padding: 0 1rem; }
        .nav { display: flex; gap: 1rem; margin-bottom: 2rem; }
        .nav button { padding: 0.5rem 1rem; cursor: pointer; }
        .nav button.active { background: #2563eb; color: white; border: none; border-radius: 4px; }
        .view { padding: 1rem; border: 1px solid #e5e7eb; border-radius: 8px; }
    </style>
</head>
<body>
    <nav class="nav">
        <button id="btn-home" class="active">Home</button>
        <button id="btn-about">About</button>
    </nav>
    <div id="main-content" class="view"></div>

    <script>
        const mainContent = document.getElementById("main-content");
        let currentView = "home";

        function renderHome() {
            mainContent.innerHTML = `
                <h2>Willkommen</h2>
                <p>Dies ist die Home-Ansicht der minimalen SPA.</p>`;
        }

        function renderAbout() {
            mainContent.innerHTML = `
                <h2>Über uns</h2>
                <p>Wir sind ein Beispiel-Projekt für Single-Page Applications.</p>`;
        }

        function render() {
            document.querySelectorAll(".nav button").forEach(b => b.classList.remove("active"));
            if (currentView === "home") {
                document.getElementById("btn-home").classList.add("active");
                renderHome();
            } else {
                document.getElementById("btn-about").classList.add("active");
                renderAbout();
            }
        }

        document.getElementById("btn-home").addEventListener("click", () => { currentView = "home"; render(); });
        document.getElementById("btn-about").addEventListener("click", () => { currentView = "about"; render(); });

        render(); // Initiales Rendering
    </script>
</body>
</html>
```

2. **Öffne die Datei im Browser** und klicke zwischen Home und About hin und her.

3. **Beobachte im Browser-Entwickler-Tools:**
   - Unter dem Tab "Elements" siehst du, dass sich nur der Inhalt von `#main-content` ändert
   - Die Seite wird **nie neu geladen** (kein Flash, kein Reload-Symbol)

**Reflexionsfragen**:
1. Was passiert, wenn du in der Browser-Adresse `#about` anhängst? (Hinweis: Das ist Hash-Routing – eine Erweiterungsmöglichkeit)
2. Wie würdest du die `render()`-Funktion ändern, um einen dritten View hinzuzufügen?

## UE_05.1_2 – Navigation mit drei Tabs

**Aufgabe**: Erweitere die minimale SPA um eine dritte Ansicht und ein aktives Tab-Handling.

### Schritte

1. **Füge einen dritten Tab hinzu** (z.B. "Kontakt") und eine zugehörige View-Funktion.

2. **Implementiere das aktive Tab-Handling** – genau wie im Clinical Diary:

```typescript
// TypeScript-Logik (kann in einer <script>-Datei oder inline sein):
document.querySelectorAll(".nav button").forEach(btn => {
    btn.addEventListener("click", () => {
        currentView = btn.getAttribute("data-view")!;
        render();
    });
});
```

3. **Teste**: Klicke auf alle drei Tabs und überprüfe, dass immer nur der aktive Tab hervorgehoben ist.

**Bonus**: Speichere den aktuellen Tab in `localStorage`, damit er nach einem Page Refresh wiederhergestellt wird.

**Kontrollfragen**:

2. Inwiefern unterscheidet sich dieses Vorgehen vom Clinical Diary-Projekt, wo die Tabs ebenfalls per `innerHTML` erstellt werden?

## UE_05.1_3 – Neuen Tab in der Patient-Ansicht hinzufügen

**Aufgabe**: Füge im Clinical Diary eine neue Registerkarte "Statistics" (Statistiken) in der Patienten-Ansicht hinzu.

### Schritte

1. **Öffne `frontend/ts/app.ts`** und finde die Funktion `navigatePatient()` (Zeile ~228).

2. **Füge einen neuen Tab-Button hinzu:**

```typescript
<button class="tab-btn ${tab === "patient-stats" ? "active" : ""}" 
        data-view="patient-stats">Statistics</button>
```

3. **Füge den Case im Switch-Block hinzu:**

```typescript
switch (tab) {
    case "patient-doctors": await renderPatientDoctors(); break;
    case "patient-search":  await renderPatientSearch(); break;
    case "patient-stats":   await renderPatientStats(); break;  // NEU
    default:                await renderPatientRecords();
}
```

4. **Implementiere die neue Render-Funktion:**

```typescript
async function renderPatientStats() {
    const content = document.getElementById("tab-content")!;
    try {
        const records = await api("GET", "/api/patients/me/records");
        
        // Einfache Statistiken berechnen
        const total = records.length;
        const byCategory: Record<string, number> = {};
        for (const r of records) {
            byCategory[r.category] = (byCategory[r.category] || 0) + 1;
        }
        const confirmed = records.filter((r: any) => r.confirmed).length;

        let html = `
            <h2>Meine Statistiken</h2>
            <div class="stats-grid">
                <div class="stat-card">
                    <div class="stat-value">${total}</div>
                    <div class="stat-label">Gesamt</div>
                </div>
                <div class="stat-card">
                    <div class="stat-value">${confirmed}</div>
                    <div class="stat-label">Bestätigt</div>
                </div>
                <div class="stat-card">
                    <div class="stat-value">${total - confirmed}</div>
                    <div class="stat-label">Unbestätigt</div>
                </div>
            </div>
            <h3>Nach Kategorie</h3>`;

        for (const [cat, count] of Object.entries(byCategory)) {
            html += `<p><strong>${cat}:</strong> ${count} Einträge</p>`;
        }

        content.innerHTML = html;
    } catch (e: any) {
        content.innerHTML = `<div class="alert alert-error">${e.message}</div>`;
    }
}
```

5. **Kompiliere TypeScript:**

```bash
cd frontend
npx tsc
```

6. **Starte die Anwendung** und logge dich als Patient ein. Der neue Tab sollte erscheinen.

**Kontrollfragen**:
1. Warum muss `Object.entries()` verwendet werden, um über `byCategory` zu iterieren?
2. Was würde passieren, wenn der Patient keine Records hat?
3. Wie müsstest du vorgehen, um einen vierten Tab für eine ganz andere Ansicht (z.B. "Einstellungen") hinzuzufügen?
