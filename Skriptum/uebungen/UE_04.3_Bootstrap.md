# UE_04.3 CSS – Bootstrap – Übungen

[<<](../skriptum/04.3_Bootstrap.md)

### UE_04.3_1: Bootstrap einbinden

1. Erstelle eine HTML-Seite und binde Bootstrap per CDN ein.
2. Öffne die Seite im Browser: Woran erkennst du, dass Bootstrap geladen wurde? (Teste z. B. einen `btn`-Button.)

### UE_04.3_2: Grid-System

1. Erstelle einen `container` mit einer `row` und drei `col-4`-Bereichen.
2. Erstelle darunter eine `row` mit zwei Bereichen: `col-md-6` und `col-md-6`.
3. Beobachte mit den DevTools (Gerätesimulation) den Unterschied zwischen `col-4` und `col-md-6` auf einem schmalen Display.
4. Erkläre die Bedeutung von `col-md-6`.

### UE_04.3_3: Tabellen und Buttons

1. Erstelle eine Bootstrap-Tabelle mit der Klasse `table table-striped table-hover` und drei Patienten.
2. Füge einen `btn btn-primary`-Button "Patient anlegen" und einen `btn btn-danger`-Button "Alle löschen" hinzu.
3. Erkläre die Wirkung von `table-striped`.

### UE_04.3_4: Card

1. Erstelle eine `card` für eine Diagnose (mit `card-title` und `card-text`).
2. Füge einen Link-Button hinzu.
3. Erkläre, warum oft eine eigene CSS-Datei zusätzlich zu Bootstrap verwendet wird.
