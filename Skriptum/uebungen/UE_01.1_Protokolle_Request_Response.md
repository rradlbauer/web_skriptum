### UE_01.1_1: HTTP-Methoden zuordnen

Ordne jeder Aktion in der Patientenverwaltung die passende HTTP-Methode zu (`GET`, `POST`, `PUT`, `DELETE`):

1. Einen neuen Patienten anlegen
2. Die Diagnose eines Patienten laden
3. Die Adresse eines Patienten vollständig aktualisieren
4. Einen Patienten aus der Verwaltung entfernen

### UE_01.1_2: Statuscodes

Ordne jeder Situation den passenden HTTP-Statuscode zu:

1. Die angeforderte Patientenseite existiert nicht
2. Der neue Patient wurde erfolgreich angelegt
3. Der Server stürzt während der Verarbeitung ab
4. Die Anfrage wurde erfolgreich verarbeitet
5. Der Client hat eine ungültige Anfrage gesendet

### UE_01.1_3: Request/Response im Detail

Betrachte den folgenden (vereinfachten) Request und die zugehörige Response:

```
GET /patients/3 HTTP/1.1
Host: localhost:8080
```

```
HTTP/1.1 200 OK
Content-Type: application/json

{"id":3,"name":"Eva Wagner"}
```

1. Welche HTTP-Methode wird verwendet und was bewirkt sie?
2. Welche Ressource wird angefragt?
3. Welchen Statuscode liefert die Antwort und was bedeutet er?
4. Nenne ein anderes Beispiel für einen Request, bei dem ein `Body` mitübertragen werden müsste.

### UE_01.1_4: Netzwerk-Daten beobachten

1. Öffne in den DevTools den Bereich **Network**.
2. Lade eine beliebige Webseite neu und wähle eine Anfrage aus.
3. Notiere: Methode, Statuscode, URL und den `Content-Type` der Antwort.
4. Erkläre, was du ablesen kannst.
