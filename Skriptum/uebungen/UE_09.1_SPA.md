# UE_09.1 Single Page Application (SPA) – Übungen

[<<](../skriptum/09.1_SPA.md)

### UE_09.1_1: Grundstruktur

1. Erkläre, woraus eine SPA technisch besteht (wie viele HTML-Dateien, wer rendert die Ansichten).
2. Nenne den Unterschied zum Server-side Rendering mit Thymeleaf.
3. Zeichne die Architektur: Browser (index.html, app.ts via Vite) ↔ Spring Boot (REST) ↔ MySQL.

### UE_09.1_2: Ansichten umschalten

1. Baue eine SPA mit drei Ansichten: `list` (Patientenliste), `form` (Patient anlegen), `detail` (Detailansicht).
2. Setze die Navigation mit drei Buttons um, die über `data-view` und `showView(viewId: string)` arbeiten.
3. Alle Ansichten außer der aktiven bekommen die Klasse `hidden`.

### UE_09.1_3: Medizinische Daten-Ansicht

1. Erstelle eine Ansicht "Medikamente" und eine "Impfungen".
2. Beim Umschalten auf "Medikamente" soll `loadMedications()` (Listenansicht) aufgerufen werden.
3. Erkläre, warum die Daten beim Wechsel neu geladen werden.

### UE_09.1_4: Patientenliste laden

1. Schreibe `loadPatients()` für die SPA mit Interface `Patient`, das die Tabelle füllt und vorher leert.
2. Rufe nach dem Start `showView("list")` auf.
3. Erkläre die Zeile `(view as HTMLElement).classList.toggle("hidden", view.id !== viewId)`.

### UE_09.1_5: Vor- und Nachteile

1. Nenne je drei Vorteile und drei Nachteile einer SPA.
2. Erkläre, warum SEO bei einer SPA schwieriger ist.
3. Entscheide und begründe: Würdest du für eine öffentliche Arzneimittel-Informationsseite eher eine SPA oder eine SSR-Seite einsetzen?
