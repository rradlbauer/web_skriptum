### UE_06.0_1: Warum TypeScript?

1. Erkläre in eigenen Worten, was es bedeutet, dass TypeScript ein "Superset" von JavaScript ist.
2. Nenne vier Vorteile von TypeScript gegenüber JavaScript.
3. Erkläre den Unterschied zwischen statischer und dynamischer Typisierung mit einem Beispiel.

### UE_06.0_2: Variablen & Funktionen typisieren

1. Schreibe die folgenden JavaScript-Variablen als TypeScript mit expliziten Typen: `name`, `age`, `isInsured`, `temperatures` (Array von Zahlen).
2. Typisiere die Funktion `calculateBmi(weightKg, heightM)` (Parameter und Rückgabewert).
3. Warum funktioniert `const bmi = 22.86;` auch ohne Angabe `: number`? Erkläre den Begriff Typ-Inferenz.

### UE_06.0_3: Interface Patient

1. Definiere ein Interface `Patient` mit `id`, `firstName`, `lastName`, `diagnosis`.
2. Lege einen gültigen Patienten an (mit `: Patient`).
3. Erstelle bewusst ein Objekt, bei dem ein Attribut fehlt bzw. einen falschen Typ hat – was meldet der Compiler?
4. Schreibe eine Funktion `printPatient(p: Patient): void`.

### UE_06.0_4: Union- und Array-Typen

1. Erkläre den Typ `string | null` anhand eines Beispiels (z. B. eine noch nicht bekannte Blutgruppe).
2. Lege ein `HealthRecord[]` an und befülle es mit zwei Einträgen.
3. Ein Interface mit optionaler Eigenschaft: welche Eigenschaft verwendest du mit `?` und warum?

### UE_06.0_5: JS zu TS konvertieren

Gegeben sei folgendes JavaScript aus Kapitel 05.2:

```js
const patients = [
    { id: 1, name: "Anna Maier", diagnosis: "Grippe" },
    { id: 2, name: "Bernd Huber", diagnosis: "Migräne" }
];
for (let p of patients) {
    console.log(`Patient ${p.name} hat ${p.diagnosis}`);
}
```

1. Formuliere es als TypeScript um: definiere ein Interface `Patient` und typisiere das Array und die Schleifenvariable.
2. Erkläre, welche Vorteile das Interface hier bietet.
