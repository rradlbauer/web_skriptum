# UE_07.2 TypeScript – Tabellen, Listen & Select-Boxen – Übungen

[<<](../skriptum/07.2_Tabellen_Listen_Select.md)

### UE_07.2_1: Liste befüllen

1. Erstelle ein Array `doctors: string[]` mit drei Arztnamen.
2. Befülle damit eine `<ul id="doctorList">` mit `document.createElement("li")` (`HTMLLIElement`).
3. Gib die Anzahl der Listenelemente in der Konsole aus (`list.children.length`).

### UE_07.2_2: Tabelle befüllen

1. Erstelle eine Tabelle mit Kopfzeile (`Name`, `Diagnose`, `Zimmer`).
2. Definiere ein Interface `Patient` und ein Array `Patient[]` mit drei Patienten (inkl. `room`).
3. Erzeuge pro Patient eine `tr` (`HTMLTableRowElement`) mit drei `td`-Zellen (`HTMLTableCellElement`).
4. Prüfe im Browser, dass die Tabelle korrekt gefüllt wird.

### UE_07.2_3: Select-Box befüllen

1. Erstelle eine `<select id="stationSelect">`.
2. Befülle sie mit drei Stationen (`value` und Anzeigetext) – definiere ein Interface `Ward`.
3. Lese nach dem Befüllen den Wert der zuerst angezeigten Option (`selectedIndex`) aus.

### UE_07.2_4: Tabelle leeren

1. Erweitere das Beispiel aus UE_07.2_2: ein Button soll die Tabelle neu befüllen, vorher aber die alten Zeilen entfernen.
2. Schreibe die Funktion `clearTableRows(table: HTMLTableElement): void` nach.
3. Erkläre, warum das Leeren nötig ist.

### UE_07.2_5: Erzeugen vs. innerHTML

1. Schreibe die Tabellenbefüllung zusätzlich mit `innerHTML +=` um.
2. Erkläre den Unterschied der beiden Ansätze und warum `createElement` bei Benutzereingaben sicherer ist.
3. Nenne die konkreten Elementtypen, die `createElement` in dieser Aufgabe zurückgibt.
