### UE_08.1_1: CRUD-Endpoints schreiben

Schreibe für eine Entität `Patient` mit den Feldern `id`, `firstName`, `lastName`, `diagnosis`:

1. Einen `GET /api/patients`-Endpoint, der alle Patienten als Liste liefert.
2. Einen `GET /api/patients/{id}`-Endpoint, der einen Patienten liefert oder `404`.
3. Einen `POST /api/patients`-Endpoint, der einen neuen Patienten anlegt (`@RequestBody`).
4. Einen `DELETE /api/patients/{id}`-Endpoint.

1. `@PathVariable Long id` bei `GET /api/patients/{id}`

3. `@RequestParam String q` bei `GET /api/patients/search?q=Maier`
