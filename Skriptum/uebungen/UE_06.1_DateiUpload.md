## Übung 06.1_1: Datei-Upload mit curl

**Aufgabe:**

1. Erstelle eine Test-Datei auf deinem Computer (z.B. `test.txt` mit dem Inhalt "Testbefund").

2. Lade die Datei mit `curl` hoch:
```bash
curl -X POST http://localhost:8080/api/patients/me/records/1/attachments \
  -H "Authorization: Bearer <DEIN_TOKEN>" \
  -F "file=@test.txt"
```

3. **Frage:** Was antwortet der Server? Welche Felder enthält die Antwort?

4. Überprüfe, ob die Datei im `uploads/`-Ordner erschienen ist. Wie heißt sie?
