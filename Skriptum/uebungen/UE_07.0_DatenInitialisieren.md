# Übungen zu 07.0 – Daten initialisieren

## UE_07.0_1 – Neuen Patienten mit 3 Health Records hinzufügen

**Aufgabe**: Erweitere die `DataInitializer.java` um einen neuen Patienten mit drei verschiedenen Health Records.

### Schritte

1. **Öffne** `backend/src/main/java/com/clinicaldiary/config/DataInitializer.java`.

2. **Füge einen neuen Patienten** nach den bestehenden Patienten hinzu (nach Zeile ~63):

```java
Patient patient4 = new Patient();
patient4.setEmail("lisa.braun@email.at");
patient4.setPassword(passwordEncoder.encode("password123"));
patient4.setSsn("5566778899");
patient4.setFirstName("Lisa");
patient4.setLastName("Braun");
patient4.setDateOfBirth("1995-03-20");
patientRepo.save(patient4);
```

3. **Füge drei Health Records** für diesen Patienten hinzu:

```java
// Record 1: Impfung
HealthRecord recordLisa1 = new HealthRecord();
recordLisa1.setPatientId(patient4.getId());
recordLisa1.setCategory("VACCINATION");
recordLisa1.setTitle("Influenza Impfung");
recordLisa1.setVaccineName("Vaxigrip Tetra");
recordLisa1.setDoseNumber(1);
recordLisa1.setBatchNumber("BATCH-FLU-2025");
recordLisa1.setInstitution("Hausarzt Dr. Bauer");
recordLisa1.setDateFrom("2025-10-15");
recordLisa1.setCreatedAt("2025-10-15T11:00:00");
recordLisa1.setUpdatedAt("2025-10-15T11:00:00");
recordRepo.save(recordLisa1);

// Record 2: Medikament
HealthRecord recordLisa2 = new HealthRecord();
recordLisa2.setPatientId(patient4.getId());
recordLisa2.setCategory("MEDICATION");
recordLisa2.setTitle("Vitamin D");
recordLisa2.setDescription("Nahrungsergänzungsmittel im Winter");
recordLisa2.setMedicationName("Vitamin D3");
recordLisa2.setDosage("1000 IE");
recordLisa2.setFrequency("Täglich");
recordLisa2.setPrescribingDoctor("Dr. Michael Bauer");
recordLisa2.setDateFrom("2025-11-01");
recordLisa2.setCreatedAt("2025-11-01T09:00:00");
recordLisa2.setUpdatedAt("2025-11-01T09:00:00");
recordRepo.save(recordLisa2);

// Record 3: Krankheit
HealthRecord recordLisa3 = new HealthRecord();
recordLisa3.setPatientId(patient4.getId());
recordLisa3.setCategory("ILLNESS");
recordLisa3.setTitle("Magen-Darm-Grippe");
recordLisa3.setDescription("Übelkeit, Erbrechen, 2 Tage Bettruhe");
recordLisa3.setDateFrom("2025-09-10");
recordLisa3.setDateTo("2025-09-12");
recordLisa3.setSeverity("Moderate");
recordLisa3.setNotes("Viel trinken, keine besondere Medikation");
recordLisa3.setCreatedAt("2025-09-10T14:00:00");
recordLisa3.setUpdatedAt("2025-09-12T18:00:00");
recordRepo.save(recordLisa3);
```

4. **Starte die Anwendung neu** und logge dich als `lisa.braun@email.at` / `password123` ein. Überprüfe, ob alle drei Records sichtbar sind.

**Kontrollfragen**:
1. Warum muss `patientRepo.save(patient4)` aufgerufen werden, bevor die Records erstellt werden können?
2. Was passiert, wenn du `patient4.getId()` aufrufst, bevor `save()` ausgeführt wurde?
3. Welche Felder sind für welche Kategorie (ILLNESS, VACCINATION, MEDICATION) relevant?

## UE_07.0_2 – ICD-10 Codes erstellen und zuweisen

**Aufgabe**: Erstelle neue ICD-10-Codes und weise sie einem bestehenden Record zu.

### Schritte

1. **Füge neue ICD-10-Codes** in der `DataInitializer.java` hinzu:

```java
Icd10Code b34 = new Icd10Code();
b34.setCode("B34");
b34.setDescription("Other viral disease, unspecified");
icd10Repo.save(b34);

Icd10Code k52 = new Icd10Code();
k52.setCode("K52");
k52.setDescription("Non-infective gastroenteritis and colitis");
icd10Repo.save(k52);

Icd10Code z29 = new Icd10Code();
z29.setCode("Z29");
z29.setDescription("Prophylactic vaccination and inoculation");
icd10Repo.save(z29);
```

2. **Weise den neuen Code K52** dem Record "Magen-Darm-Grippe" von Lisa Braun zu:

```java
RecordIcd10 ri2 = new RecordIcd10();
ri2.setRecordId(recordLisa3.getId());
ri2.setIcd10CodeId(k52.getId());
ri2.setIcd10Code("K52");
ri2.setIcd10Description("Non-infective gastroenteritis and colitis");
ri2.setDoctorId(doctor1.getId());
ri2.setAssignedAt("2025-09-13T10:00:00");
recordIcd10Repo.save(ri2);
```

3. **Starte die Anwendung neu** und überprüfe:
   - Im Doctor-View: Ist der ICD-10-Code "K52" bei dem Record sichtbar?
   - Im ICD-10-Suche-Tab: Können die neuen Codes gefunden werden?

**Kontrollfragen**:
1. Was ist der Unterschied zwischen `recordIcd10Repo` und `icd10Repo`?
2. Warum werden ICD-10-Beschreibungen in `RecordIcd10` dupliziert (neben der ID)?
3. Was würde passieren, wenn der gleiche ICD-10-Code zweimal demselben Record zugewiesen würde?

## UE_07.0_3 – Neuen Arzt mit besonderer Fachrichtung erstellen

**Aufgabe**: Erstelle einen neuen Arzt mit einer anderen Fachrichtung und weise ihn allen Patienten zu.

### Schritte

1. **Erstelle einen neuen Arzt:**

```java
Doctor doctor4 = new Doctor();
doctor4.setEmail("dr.schneider@klinik.at");
doctor4.setPassword(passwordEncoder.encode("doctor123"));
doctor4.setMedicalLicenseNumber("L-22222");
doctor4.setFirstName("Elena");
doctor4.setLastName("Schneider");
doctor4.setSpecialization("Pediatrics");
doctor4.setActive(true);
doctorRepo.save(doctor4);
```

2. **Weise alle vier Patienten** diesem Arzt zu:

```java
// Für jeden Patienten eine Zuordnung erstellen
Patient[] allPatients = { patient1, patient2, patient3, patient4 };
for (Patient p : allPatients) {
    DoctorPatient dp = new DoctorPatient();
    dp.setDoctorId(doctor4.getId());
    dp.setPatientId(p.getId());
    dp.setAssignedAt("2025-07-01T10:00:00");
    doctorPatientRepo.save(dp);
}
```

3. **Teste die Zuordnung:**
   - Logge dich als Patient ein → "My Doctors" Tab → Ist Dr. Schneider sichtbar?
   - Logge dich als Dr. Schneider ein (dr.schneider@klinik.at / doctor123) → "My Patients" Tab → Sind alle vier Patienten sichtbar?

**Bonus**: Erstelle einen zweiten Arzt mit der Fachrichtung "Neurology" und weise ihm nur Anna Schmidt und Maria Weber zu.

**Kontrollfragen**:
1. Was passiert, wenn du versuchst, einen Arzt ohne `active: true` zu erstellen? Kann man sich als dieser Arzt einloggen?
2. Warum muss `doctor4.getId()` aufgerufen werden, bevor die Zuordnungen erstellt werden können?
3. Wie würdest du vorgehen, wenn du die Zuordnungen nachträglich ändern wolltest (z.B. einen Patienten von einem Arzt entfernen)?
