# UE_07.1 TypeScript – Formulare auslesen & befüllen – Übungen

### UE_07.1_1: Formular auslesen

1. Erstelle ein Formular mit den Feldern: Name (text), Alter (number), Station (select) und einer Checkbox "versichert".
2. Schreibe TypeScript, das beim `submit` alle Werte in ein Objekt `patient` sammelt (mit Interface `PatientFormData`) und mit `console.log` ausgibt.
3. Vergiss `event.preventDefault()` nicht – erkläre, warum er nötig ist.

### UE_07.1_2: Checkbox, Radio und Typen

1. Füge eine Checkbox `insured` und zwei Radio-Buttons `gender` hinzu.
2. Lies `.checked` der Checkbox aus (was ist der Typ der Variablen?).
3. Lies den Wert des ausgewählten Radio-Buttons mit `querySelector('input[name="gender"]:checked') as HTMLInputElement`.
4. Erkläre den Unterschied zwischen `.value` und `.checked`.
5. Erkläre die Bedeutung der `as`-Annahmen und was passiert, wenn das Element nicht gefunden wird.

### UE_07.1_3: Formular befüllen

1. Schreibe eine Funktion `fillPatientForm(patient: PatientFormData): void`, die alle Felder befüllt.
2. Lege ein Objekt `demoPatient` an und befülle auf einen Button-Klick hin das Formular.
3. Überprüfe im Browser, dass die Werte erscheinen.

### UE_07.1_4: Ausgabe als JSON

1. Erweitere das `submit`-Event: gib das gesammelte Objekt mit `JSON.stringify` in der Konsole aus.
2. Erkläre, wofür dieses JSON später nützlich sein könnte (Senden an eine REST-API).
3. Warum musst du bei einem Zahlenfeld `Number(...)` verwenden?

### UE_07.1_5: Hilfsfunktion

1. Schreibe die Hilfsfunktion `inputValue(id: string): string` aus dem Kapitel.
2. Verwende sie im `submit`-Event, um `name` und `age` zu lesen.
3. Erkläre, welchen Vorteil sie gegenüber wiederholten `as HTMLInputElement`-Angaben bietet.
