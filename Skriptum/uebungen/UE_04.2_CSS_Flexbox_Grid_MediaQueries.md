### UE_04.2_1: Flexbox

1. Erstelle ein `div` mit drei Kind-Elementen (z. B. drei `div` mit unterschiedlichen Farben).
2. Setze `display: flex` auf den Container und beobachte die Anordnung.
3. Probiere `justify-content: center`, `flex-end`, `space-between` und `align-items: center` aus.
4. Wie zentrierst du ein Element exakt in der Mitte (horizontal und vertikal)? Schreibe die CSS-Regeln auf.

### UE_04.2_2: Grid-Layout

1. Erstelle ein Grid mit vier "Diagnose-Karten", die auf Desktop in **zwei Spalten** angeordnet sind (`grid-template-columns: repeat(2, 1fr)`).
2. Ergänze `gap: 16px`.
3. Erkläre, was `1fr` bedeutet.

### UE_04.2_3: Media Queries

1. Erweitere das Grid aus Aufgabe 2 so, dass es unterhalb von `600px` Breite **eine Spalte** zeigt (`@media (max-width: 600px)`).
2. Nutze die DevTools (Browseransicht "Gerät simulieren", z. B. Handy-Modus) und beobachte den Wechsel.
3. Erkläre den Begriff "Breakpoint".

### UE_04.2_4: Flex vs. Grid

1. Nenne je ein Beispiel aus einer Patientenverwaltung, bei dem du Flexbox verwenden würdest, und eines, bei dem Grid besser passt und begründe.
2. Erkläre den Unterschied: Flexbox zielt auf eine Achse, Grid auf zwei Achsen.
