### UE_01.0_1: Begriffe zuordnen

Ordne die folgenden Begriffe dem Client oder dem Server zu und begründe kurz:

1. Browser
2. MySQL-Datenbankserver
3. `fetch`-Aufruf in JavaScript
4. Eingebauter Tomcat-Server in Spring Boot
5. Mobile App, die Laborwerte anzeigt

### UE_01.0_2: Rollen beschreiben

Stell dir ein **Terminbuchungssystem** einer Arztpraxis vor. Der Browser ist der Client, die Spring-Boot-Anwendung der Server.

1. Welche Anfragen könnte der Client an den Server schicken (mindestens drei)?
2. Was könnte der Server als Antwort liefern?
3. Erkläre, warum der Server dauerhaft erreichbar sein muss, der Client aber nicht.

### UE_01.0_3: Diagramm zeichnen

1. Zeichne ein einfaches Diagramm für das Client-Server-Modell mit **drei Clients** und **einem Server**.
2. Füge die Begriffe "Request" und "Response" an den passenden Stellen ein.
3. Unterstreiche die Seite, die die Kommunikation jeweils **initiiert** (startet).
