## UE_02.0_3 – Anwendung starten und H2-Konsole verwenden

**Aufgabe**: Starte die Spring Boot Anwendung und nutze die H2-Konsole.

### Schritte

1. **Starte die Anwendung**:
   ```bash
   cd backend
   ./mvnw spring-boot:run
   ```
   (oder `mvnw.cmd spring-boot:run` unter Windows)

2. **Öffne die H2-Konsole** im Browser:
   ```
   http://localhost:8080/h2-console
   ```

3. **Verbinde dich** mit der Datenbank:
   - JDBC URL: `jdbc:h2:mem:clinicaldiary`
   - User Name: `sa`
   - Password: *(leer)*

4. **Erkunde die Tabellen**: Führe folgenden SQL-Befehl aus:
   ```sql
   SELECT * FROM PATIENTS;
   ```

**Reflexionsfragen**:
- Wie viele Tabellen wurden automatisch erstellt?
- Welche Tabellen enthalten Beispieldaten? Woher kommen diese?
- Was passiert mit den Daten, wenn du die Anwendung neu startest?
