# UE_08.2 Spring Boot – Services, Entities & Repositories – Übungen

[<<](../skriptum/08.2_Services_Entities_Repositories.md)

### UE_08.2_1: Entity modellieren

1. Erstelle eine Entity `Diagnosis` mit den Feldern: `id` (Long, automatisch), `code` (String, nicht null) und `description` (String).
2. Verwende `@Entity`, `@Table(name = "diagnoses")`, `@Id` und `@GeneratedValue`.
3. Schreibe Getter und Setter für alle Felder.

### UE_08.2_2: Repository

1. Lege das Interface `DiagnosisRepository` an, das `JpaRepository<Diagnosis, Long>` erweitert.
2. Füge eine Suchmethode `findByCodeContaining(String code)` hinzu.
3. Erkläre, wie Spring aus `findByLastNameContaining` die SQL-Query ableitet (welcher SQL-Klausel entspricht es?).

### UE_08.2_3: Service

1. Erstelle eine Klasse `DiagnosisService` mit `@Service`.
2. Injiziere das Repository über den Konstruktor.
3. Schreibe eine Methode `createDiagnosis(Diagnosis d)`, die eine leere `code` mit einer Exception ablehnt.

### UE_08.2_4: Zusammenspiel

1. Ergänze den Controller `DiagnosisController` so, dass er die Service-Methoden und nicht direkt das Repository verwendet.
2. Zeichne das Schichtendiagramm für `Diagnosis`.
3. Erkläre den Begriff "Dependency Injection" und warum der Konstruktor dafür genutzt wird.

### UE_08.2_5: JSON-Serialisierung

1. Erkläre, warum eine Entity automatisch als JSON an den Client geliefert wird.
2. Welche Rolle spielen die Getter-Methoden dabei?
3. Angenommen, die Entity hat ein Attribut `password` – warum wäre es problematisch, wenn es in der JSON-Antwort auftaucht? (Überlege kurz, wie du es ausschließen könntest.)
