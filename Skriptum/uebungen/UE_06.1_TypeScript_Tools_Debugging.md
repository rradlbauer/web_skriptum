### UE_06.1_1: Node.js und npm

1. Prüfe, ob Node.js und npm installiert sind (`node --version`, `npm --version`).
2. Erkläre, wofür `package.json` und `node_modules` dienen.
3. Was bewirkt `npm install --save-dev typescript`?

### UE_06.1_2: tsc ausprobieren

1. Lege die Datei `src/patient.ts` mit folgendem Inhalt an:

```ts
interface Patient {
    id: number;
    name: string;
}

const p: Patient = { id: 1, name: "Anna Maier" };
console.log(p.name);
```

2. Compiliere mit `npx tsc src/patient.ts` und prüfe die erzeugte `.js`-Datei.
3. Füge bewusst einen Typfehler ein und beobachte die Compiler-Meldung. Nenne die Fehlerzeile und -art.
4. Teste `npx tsc --watch`.

### UE_06.1_3: tsconfig.json

1. Erzeuge mit `npx tsc --init` eine `tsconfig.json`.
2. Erkläre die Optionen `target`, `strict`, `rootDir`, `outDir` und `sourceMap`.
3. Wie sieht die Verzeichnisstruktur aus, wenn `rootDir: "src"` und `outDir: "dist"` gesetzt sind?

### UE_06.1_4: Debugging

1. Setze in `src/main.ts` (oder deiner `.ts`-Datei) einen Haltepunkt und starte das Debugging in **VS Code** (Konfiguration in `.vscode/launch.json`).
2. Öffne zusätzlich die Seite in Chrome und debugge im **Sources**-Bereich der DevTools. Wo siehst du die `.ts`-Datei und warum (Source Maps)?
3. Steige mit "Step over" durch eine Funktion und protokolliere die Werte einer Variable.
4. Erkläre den Zusammenhang zwischen `sourceMap: true` und dem Anzeigen der `.ts`-Datei im Browser.
