## UE_03.1_1 – Gesundheitsakte nach Patient-ID abrufen

**Aufgabe**: Erstelle eine Repository-Methode, die alle Gesundheitsakten eines bestimmten Patienten findet, sortiert nach Erstellungsdatum (absteigend).

### Schritte

1. **Öffne** `HealthRecordRepository.java`
2. **Überprüfe** die bestehende Methode `findByPatientIdOrderByCreatedAtDesc`
3. **Erstelle** eine weitere Methode, die nur Akten einer bestimmten **Kategorie** zurückgibt:

```java
// Alle Gesundheitsakten eines Patienten mit bestimmter Kategorie
List<HealthRecord> findByPatientIdAndCategoryOrderByCreatedAtDesc(
    Long patientId, String category);
```

4. **Teste** die Methode im `PatientController`:

```java
@GetMapping("/me/records/{category}")
public ResponseEntity<?> getRecordsByCategory(
        Authentication auth, @PathVariable String category) {
    Long patientId = getCurrentPatientId(auth);
    List<HealthRecord> records = recordRepo
        .findByPatientIdAndCategoryOrderByCreatedAtDesc(patientId, category);
    return ResponseEntity.ok(records);
}
```

### Reflexionsfragen
- Wie übersetzt Spring den Methodennamen in eine SQL-Query?
- Was passiert, wenn keine Einträge vorhanden sind?
- Welche anderen Kombinationen von `findBy`-Bedingungen könnt ihr euch vorstellen?

## UE_03.1_2 – Existenz-Prüfung im DoctorPatientRepository

**Aufgabe**: Füge dem `DoctorPatientRepository` eine Methode hinzu, die prüft, ob eine bestimmte Arzt-Patienten-Zuordnung existiert.

### Schritte

1. **Öffne** `DoctorPatientRepository.java`
2. **Überprüfe** die bestehende Methode `existsByDoctorIdAndPatientId`
3. **Erstelle** eine weitere Methode, die die **Anzahl** der Patienten eines Arztes zurückgibt:

```java
// Anzahl der Patienten eines Arztes
@Query("SELECT COUNT(dp) FROM DoctorPatient dp WHERE dp.doctorId = :doctorId")
long countPatientsByDoctorId(Long doctorId);
```

4. **Erstelle** eine Methode, die die **Anzahl** der Ärzte eines Patienten zurückgibt:

```java
// Anzahl der Ärzte eines Patienten
@Query("SELECT COUNT(dp) FROM DoctorPatient dp WHERE dp.patientId = :patientId")
long countDoctorsByPatientId(Long patientId);
```

### Test

Füge einen Endpoint im `DoctorController` hinzu:

```java
@GetMapping("/me/stats")
public ResponseEntity<?> getDoctorStats(Authentication auth) {
    Long doctorId = getCurrentDoctorId(auth);
    Map<String, Object> stats = new HashMap<>();
    stats.put("totalPatients", doctorPatientRepo.countPatientsByDoctorId(doctorId));
    return ResponseEntity.ok(stats);
```

## UE_03.1_3 – Neue Entität "LabResult" erstellen

**Aufgabe**: Erstelle eine neue Entität `LabResult` (Laborbefund), die mit einer Gesundheitsakte verknüpft ist.

### Schritte

1. **Erstelle** die Entität `LabResult.java`:

```java
@Entity
@Table(name = "lab_results")
public class LabResult {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private Long healthRecordId;     // FK zu HealthRecord

    @Column(nullable = false)
    private String testName;

    private String resultValue;
    private String unit;
    private String normalRange;
    private String performedAt;

    public LabResult() {}

    // Getter und Setter...
}
```

2. **Erstelle** das Repository `LabResultRepository.java`:

```java
public interface LabResultRepository extends JpaRepository<LabResult, Long> {

    // Alle Laboreinträge einer Gesundheitsakte
    List<LabResult> findByHealthRecordIdOrderByPerformedAtDesc(Long healthRecordId);

    // Laboreintrag mit bestimmtem Namen
    Optional<LabResult> findByHealthRecordIdAndTestName(Long healthRecordId, String testName);
}
```

3. **Erstelle** einen `LabResultController` mit folgenden Endpoints:

| Methode | URL | Beschreibung |
|---------|-----|-------------|
| GET | `/api/records/{recordId}/lab-results` | Alle Laboreinträge für eine Gesundheitsakte |
| POST | `/api/records/{recordId}/lab-results` | Neuen Laboreintrag erstellen |
| DELETE | `/api/records/{recordId}/lab-results/{labResultId}` | Laboreintrag löschen |

### Test

1. Starte die Anwendung
2. Überprüfe in der H2-Konsole, ob die Tabelle `LAB_RESULTS` erstellt wurde
3. Erstelle einen Laboreintrag über den neuen Endpoint

### Bonus

Erweitere den `enrichRecord()`-Methoden in `PatientController` und `DoctorController`, sodass die Laboreinträge in der Gesundheitsakte mit angezeigt werden:

```java
// In enrichRecord():
m.put("labResults", labResultRepo.findByHealthRecordIdOrderByPerformedAtDesc(r.getId())
    .stream().map(lr -> {
        Map<String, Object> lm = new HashMap<>();
        lm.put("id", lr.getId());
        lm.put("testName", lr.getTestName());
        lm.put("resultValue", lr.getResultValue());
        return lm;
    }).collect(Collectors.toList()));
```
