# UE_05.2 JavaScript – Objekte & JSON – Übungen

[<<](../skriptum/05.2_JavaScript_Objekte_JSON.md)

### UE_05.2_1: Objekt anlegen

1. Lege ein Objekt `patient` mit `id`, `name`, `age` und `diagnosis` an.
2. Greife mit Punkt-Notation auf `name` zu und mit Klammer-Notation auf `diagnosis`.
3. Ändere `age` und füge `room` hinzu.

### UE_05.2_2: Verschachtelte Objekte

1. Lege ein Objekt `admission` an mit:
   - `date` (z. B. "2026-09-01")
   - `ward` (z. B. "Innere")
   - `room`: ein Objekt mit `number` und `floor`
2. Gib `room.number` und `admission.ward` aus.

### UE_05.2_3: Array von Objekten

1. Erstelle ein Array mit drei Patienten (siehe Kapitel).
2. Gib mit einer `for...of`-Schleife für jeden Patienten `name` und `diagnosis` aus (Template Literals).

### UE_05.2_4: Objekt ↔ JSON

1. Verwandle das Patienten-Array mit `JSON.stringify` in einen JSON-Text und gib ihn aus.
2. Verwandle den Text mit `JSON.parse` zurück und gib den Namen des zweiten Patienten aus.
3. Erkläre den Unterschied zwischen einem JavaScript-Objekt und einem JSON-Text.

### UE_05.2_5: JSON mit Serverdaten

Du erhältst von einer REST-API folgenden JSON-Text:

```json
[{"id":4,"name":"Karl Gruber","diagnosis":"Asthma"}]
```

1. Schreibe den Code, um diesen Text in ein Array zu parsen.
2. Gib `name` und `diagnosis` des Patienten aus.
